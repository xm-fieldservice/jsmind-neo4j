# 日志系统整改实施方案

## 问题背景分析

基于用户反馈的四个核心需求点：

1. **实时日志采集框** - 作为标准组件嵌入各页面
2. **全代码活动记录** - 防止功能覆盖、架构偏离、模块破坏
3. **持久化保存** - 异步同步到本地存储
4. **内存管理** - FIFO机制，合理容量

## 当前系统问题诊断

### 现有组件分析

| 组件 | 功能 | 问题 |
|------|------|------|
| [`UnifiedLogger`](src/core/UnifiedLogger.js:1) | 统一日志记录 | 控制台拦截未激活，集成不完善 |
| [`LogCollector`](src/utils/LogCollector.js:1) | 控制台拦截采集 | 与UnifiedLogger功能重叠 |
| [`LogPanel`](src/components/LogPanel.js:1) | UI日志显示 | 未标准化，嵌入方式复杂 |
| [`ErrorHandler`](src/core/ErrorHandler.js:1) | 错误处理 | 日志集成不完善 |

### 核心问题
- **功能重复**: 3个组件都做控制台拦截
- **集成缺失**: 组件间缺乏统一协调
- **持久化缺失**: 日志仅存在于内存
- **标准化不足**: 没有统一的嵌入规范

### 第二阶段：功能增强（3-5天）

#### 2.1 实现FIFO内存管理

```javascript
// src/core/LogBufferManager.js
class LogBufferManager {
    constructor(maxSize = 1000) {
        this.buffer = new CircularBuffer(maxSize);
        this.stats = {
            totalLogged: 0,
            bufferOverflows: 0,
            memoryUsage: 0
        };
    }
    
    add(entry) {
        if (this.buffer.isFull()) {
            const removed = this.buffer.removeOldest();
            this.stats.bufferOverflows++;
            this._cleanupRemovedEntry(removed);
        }
        
        this.buffer.add(entry);
        this.stats.totalLogged++;
        this._updateMemoryStats();
    }
    
    // 环形缓冲区实现
    class CircularBuffer {
        constructor(capacity) {
            this.buffer = new Array(capacity);
            this.head = 0;
            this.tail = 0;
            this.size = 0;
            this.capacity = capacity;
        }
        
        add(item) {
            this.buffer[this.tail] = item;
            this.tail = (this.tail + 1) % this.capacity;
            if (this.size === this.capacity) {
                this.head = (this.head + 1) % this.capacity;
            } else {
                this.size++;
            }
        }
    }
}
```

#### 2.2 实现异步持久化

```javascript
// src/core/LogPersistence.js
class LogPersistence {
    constructor() {
        this.storage = window.AutogenUnifiedStorage;
        this.batchSize = 50;
        this.batchQueue = [];
        this.flushInterval = 5000; // 5秒批量保存
        this._startFlushTimer();
    }
    
    async save(entry) {
        this.batchQueue.push(entry);
        
        if (this.batchQueue.length >= this.batchSize) {
            await this._flushBatch();
        }
    }
    
    async _flushBatch() {
        if (this.batchQueue.length === 0) return;
        
        const batch = [...this.batchQueue];
        this.batchQueue = [];
        
        try {
            const timestamp = Date.now();
            const key = `logs_${timestamp}_${Math.random().toString(36).slice(2)}`;
            await this.storage.store('system', key, {
                entries: batch,
                timestamp: new Date().toISOString(),
                count: batch.length
            });
        } catch (error) {
            console.warn('日志持久化失败:', error);
            // 回退到队列，下次重试
            this.batchQueue.unshift(...batch);
        }
    }
}
```

### 第三阶段：全代码覆盖（1周）

#### 3.1 强制控制台拦截

```javascript
// src/core/ConsoleInterceptor.js
class ConsoleInterceptor {
    constructor(loggingFacade) {
        this.facade = loggingFacade;
        this.originalConsole = { ...console };
        this._interceptAll();
    }
    
    _interceptAll() {
        const methods = ['log', 'info', 'warn', 'error', 'debug'];
        
        methods.forEach(method => {
            const original = console[method];
            console[method] = (...args) => {
                // 记录到统一日志系统
                const level = this._mapConsoleLevel(method);
                const message = this._formatArgs(args);
                this.facade.log(level, 'system', message, { originalArgs: args });
                
                // 保持原有功能
                original.apply(console, args);
            };
        });
    }
    
    _mapConsoleLevel(method) {
        const map = {
            'log': 'INFO',
            'info': 'INFO', 
            'warn': 'WARN',
            'error': 'ERROR',
            'debug': 'DEBUG'
        };
        return map[method] || 'INFO';
    }
}
```

#### 3.2 架构偏离检测

```javascript
// src/core/ArchitectureGuard.js
class ArchitectureGuard {
    constructor() {
        this.rules = this._loadArchitectureRules();
        this.violations = [];
    }
    
    checkModuleUsage(moduleName, context) {
        const rule = this.rules[moduleName];
        if (!rule) return true;
        
        // 检查是否违反架构规则
        if (rule.deprecated && context.usage === 'direct') {
            this._recordViolation({
                type: 'DEPRECATED_USAGE',
                module: moduleName,
                context,
                message: `直接使用已弃用模块: ${moduleName}`
            });
            return false;
        }
        
        return true;
    }
    
    _recordViolation(violation) {
        this.violations.push(violation);
        
        // 记录到日志系统
        window.UnifiedLoggingFacade.log('WARN', 'architecture', 
            `架构违规: ${violation.message}`, violation);
    }
}
```
