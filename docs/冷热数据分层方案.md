## 冷热数据分层存储核心概念

### 数据分类定义

**热数据（Hot Data）**
- **特征**：频繁访问（日访问>100次）
- **响应要求**：毫秒级（<10ms）
- **存储介质**：NVMe SSD、内存
- **典型场景**：AI模型参数、实时推理数据、用户会话

**温数据（Warm Data）**
- **特征**：中等频率访问（周访问10-100次）
- **响应要求**：秒级（1-5s）
- **存储介质**：SATA SSD、高速HDD
- **典型场景**：训练数据集、历史模型版本

**冷数据（Cold Data）**
- **特征**：低频访问（月访问<10次）
- **响应要求**：分钟级（1-10min）
- **存储介质**：机械硬盘、磁带、云归档
- **典型场景**：原始数据集、备份数据、审计日志

def calculate_data_temperature(file_path):
    metrics = {
        'access_frequency': get_access_count(file_path, days=30),
        'last_access_time': get_last_access_time(file_path),
        'file_size': get_file_size(file_path),
        'user_priority': get_user_priority(file_path)
    }
    
    # 热度评分计算
    temperature_score = (
        metrics['access_frequency'] * 0.4 +
        time_decay_factor(metrics['last_access_time']) * 0.3 +
        size_factor(metrics['file_size']) * 0.2 +
        metrics['user_priority'] * 0.1
    )
    
    if temperature_score > 80: return "HOT"
    elif temperature_score > 40: return "WARM"
    else: return "COLD"

**智能数据路由系统**
```python
# 阿里云环境下的数据路由实现
class AliyunDataRouter:
    def __init__(self):
        self.redis_client = Redis(host='redis-cluster.aliyun.com')
        self.oss_client = OSS(endpoint='oss-cn-hangzhou.aliyuncs.com')
        self.local_storage = LocalStorage('/data/hot')
        
    def get_data(self, data_id):
        # 1. 先查Redis热缓存
        if data := self.redis_client.get(data_id):
            return data
            
        # 2. 查本地SSD热存储
        if data := self.local_storage.get(data_id):
            self.redis_client.setex(data_id, 3600, data)  # 缓存1小时
            return data
            
        # 3. 查OSS温数据
        if data := self.oss_client.get_object('warm-bucket', data_id):
            self.promote_to_hot(data_id, data)  # 提升为热数据
            return data
            
        # 4. 查OSS冷数据/归档
        return self.retrieve_from_cold_storage(data_id)
```
