需求叙述（根据截图的节点详情栏标签呈现方式）
数据结构来源
标签面板的数据来自脑图中的“标签管理”节点。
结构为“标签组”→“标签”的父子关系，严格按截图所示层级：左侧是分组（如“常规 / AI / 笔记”），右侧为该分组下的标签（如“项目/里程碑/完成/进行中/计划”等）。
布局与分区
左侧：垂直列出所有“标签组”按钮，单选，高亮“当前分组”。
右侧：网格/流式排列该分组下的“标签”chips。
视觉样式（chips）
标签以“圆角矩形 chip”展示，填充色按分组区分（截图示意：常规为黄色系、AI为绿色系、笔记为蓝紫系）。
每个 chip 具有轻微阴影/投影、内边距、圆角、字重；激活时提升对比度（更深色或描边），悬停时有轻微提升/阴影变化。
节距：chip 间水平与垂直间距一致，右侧区域自动换行。
左侧分组按钮样式与 chips 风格统一，当前分组高亮。
交互与联动
点击右侧 chip：对“当前选中节点”切换该标签（增/删）。
标签的真实存储位置为节点内容的首行标签行，格式固定为：标签: 标签A, 标签B，与正文空一行分隔。
切换后：
立即更新节点内容的标签行（不污染标题/label）。
右侧 chip 高亮状态即时刷新（选中=已包含该标签）。
切换左侧分组：右侧 chips 切换为对应分组标签并保留与当前选中节点的联动高亮。
存储与渲染约束
节点标题/label 保持纯文本，不嵌入标签 HTML。
标签仅写入内容区首行（“标签:”行），导出/导入时可完整还原。
详情面板的视觉渲染不改变存储结构；仅根据“标签:”行计算 chip 选中与否。
可配置项
分组→颜色主题映射（组名到主色/hover/active 的色板），默认内置一套与截图风格接近的配色，可在前端配置。
chips 大小、圆角大小、间距、投影强度可通过 CSS 变量调整。
状态同步与时机
首次渲染脑图后：解析“标签管理”到面板。
切换选中节点：右侧 chip 高亮与当前节点内容同步。
修改内容编辑器并保存：重新解析“标签:”行并刷新高亮。
导入/从本地恢复：渲染后重建面板与高亮。
容错与边界
若不存在“标签管理”或某分组为空：显示“此分组暂无标签”。
标签名去重、去前后空格；大小写/全半角按原文保留。
节点内容无“标签:”行时，视为无标签。
性能与可用性
大量标签时右侧支持滚动；保持点击反馈流畅。
键盘可切换分组（可选增强），芯片支持焦点样式（可选）。
国际化：标签文本按原文显示；UI 提示文案可配置。
