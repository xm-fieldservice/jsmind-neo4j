## 🎯 v1.2核心更新：关系表达机制

### 更新背景

v1.1规范虽然支持`meta.relatedIds`、`meta.dependencies`等简单关系，但缺少：
- ❌ 关系类型定义
- ❌ 关系强度/置信度
- ❌ 关系来源追溯
- ❌ 动态发现关系的表达

v1.2通过**纯meta层扩展**补全关系表达能力（避免混合方案在AI参与时的混乱）。

## 🏗️ 核心数据结构（v1.2扩展）

### ⭐ 设计原则：单一真相来源 + metadata无限扩展

**关键决策**：所有关系数据统一存储在`meta`层
- ✅ 与v1.1的`meta.relatedIds`保持一致
- ✅ 避免AI在多处维护数据导致混乱
- ✅ 关系本质是"描述节点连接的元数据"
- ✅ 利用metadata的无限扩展能力

## 📊 设计原则：为什么选择纯meta层方案？

### ✅ 核心理由

**1. 单一真相来源（Single Source of Truth）**
- ❌ 混合方案需要同步`data.relations`和`meta.relatedIds`
- ❌ AI容易忘记同步，导致数据不一致
- ✅ 纯meta层：只有一个地方维护关系数据

**2. 架构一致性**
- ✅ v1.1已有`meta.relatedIds`、`meta.dependencies`
- ✅ 关系本质是"描述节点连接的元数据"
- ✅ meta字段支持"任意扩展"

**3. AI友好性**
- ✅ AI只需关注一个地方
- ✅ 降低认知负担
- ✅ 减少出错概率

**4. 向后兼容**
- ✅ 保留v1.1的简单ID数组
- ✅ 新增详细关系对象
- ✅ 平滑升级路径

## 🔄 关系数据的同步策略

### ⭐ 唯一策略：meta.relations 是单一真相来源

```javascript
// 关系管理服务（统一在meta层操作）
class RelationManager {
  
  // 添加关系（只操作meta.relations）
  async addRelation(nodeId, relation) {
    const node = await this.storage.get(nodeId);
    
    // 初始化
    if (!node.meta.relations) {
      node.meta.relations = [];
    }
    
    // 添加到meta.relations
    node.meta.relations.push({
      id: relation.id || `rel_${Date.now()}`,
      type: relation.type,
      targetId: relation.targetId,
      strength: relation.strength || 0.5,
      confidence: relation.confidence || 1.0,
      source: relation.source || 'user_defined',
      createdAt: Date.now(),
      ...relation
    });
    
    // 自动维护v1.1兼容字段
    this.syncCompatibilityFields(node);
    
    await this.storage.set(nodeId, node);
  }
  
  // 自动维护v1.1兼容字段
  syncCompatibilityFields(node) {
    // 从meta.relations自动生成relatedIds
    node.meta.relatedIds = [...new Set(
      node.meta.relations.map(r => r.targetId)
    )];
    
    // 从meta.relations自动生成dependencies
    node.meta.dependencies = node.meta.relations
      .filter(r => r.type === 'depends_on')
      .map(r => r.targetId);
  }
}
```

### 策略：Neo4j发现的关系回流到meta.relations

```javascript
// Neo4j发现新关系后的回流处理
async function handleNeo4jDiscovery(event) {
  const { sourceId, targetId, relationType, metadata } = event.data;
  
  const node = await storage.get(sourceId);
  
  // 初始化
  if (!node.meta.relations) {
    node.meta.relations = [];
  }
  
  // 检查是否已存在
  const exists = node.meta.relations.some(
    r => r.targetId === targetId && r.type === relationType
  );
  
  if (!exists) {
    // 添加到meta.relations
    node.meta.relations.push({
      id: `rel_${Date.now()}`,
      type: relationType,
      targetId: targetId,
      strength: metadata.strength || 0.5,
      confidence: metadata.confidence || 0.7,
      source: 'neo4j_inferred',
      createdAt: Date.now(),
      needsConfirmation: true,  // ⭐ 需要用户确认
      algorithm: metadata.algorithm,
      evidence: metadata.evidence
    });
    
    // 自动维护兼容字段
    this.syncCompatibilityFields(node);
    
    // 保存
    await storage.set(sourceId, node);
    
    // 触发UI确认事件
    this.eventBus.emit('ui:relation_needs_confirmation', {
      nodeId: sourceId,
      relation: node.meta.relations[node.meta.relations.length - 1]
    });
  }
}
```

### 数据迁移脚本

```javascript
// 将v1.1数据升级到v1.2
async function migrateToV12(node) {
  // 如果已经有data.relations，跳过
  if (node.data?.relations) {
    return node;
  }
  
  // 初始化relations数组
  node.data = node.data || {};
  node.data.relations = [];
  
  // 迁移 meta.dependencies
  if (node.meta?.dependencies?.length > 0) {
    node.meta.dependencies.forEach(targetId => {
      node.data.relations.push({
        id: `rel_${Date.now()}_${targetId}`,
        type: 'depends_on',
        targetId: targetId,
        strength: 1.0,
        confidence: 1.0,
        source: 'user_defined',
        createdAt: Date.now()
      });
    });
  }
  
  // 迁移 meta.relatedIds
  if (node.meta?.relatedIds?.length > 0) {
    node.meta.relatedIds.forEach(targetId => {
      // 避免重复（dependencies已经迁移过）
      if (!node.meta.dependencies?.includes(targetId)) {
        node.data.relations.push({
          id: `rel_${Date.now()}_${targetId}`,
          type: 'relates_to',
          targetId: targetId,
          strength: 0.5,
          confidence: 1.0,
          source: 'user_defined',
          createdAt: Date.now()
        });
      }
    });
  }
  
  // 同步到meta（保持兼容）
  syncRelationToMeta(node);
  
  return node;
}
```
