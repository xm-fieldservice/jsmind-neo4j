# 脑图实现演进说明

- 目标：统一使用 jsMind 作为脑图渲染与交互层，弃用基于 G6 的脑图实现。
- 背景：原项目同时存在 `mindmap-controller.js`（G6）与 `jsmind-controller.js`（jsMind）。为降低维护复杂度、提升前后端分离的可演进性，决定仅保留 jsMind。

## 现状
- `index.html` 仅加载 `jsmind-controller.js`，不再引用 `mindmap-controller.js`。
- 仓库仍保留旧文件以便回溯：`mindmap-controller.js`，并在文件顶部加入了“已废弃”说明。

## 模块化与后续计划
- 拆分建议目录结构：
  - `src/core/`：数据模型、遍历与变更、jsMind 树转换（如 `toJsMindTree()` / `fromJsMindTree()`）。
  - `src/ui/`：DOM 与交互事件（详情面板、快捷键、菜单等）。
  - `src/adapters/`：渲染适配层（仅 jsMind）。
  - `src/services/`：持久化与导入导出（localStorage / 未来后端 API）。
- 保持向后兼容，不破坏现有页面行为。

## 注意事项
- 仅脑图功能弃用 G6；其他可视化模块若需，可继续使用 G6。
- 未来前后端分离时，优先抽象持久化接口，替换 localStorage 为后端 API。
