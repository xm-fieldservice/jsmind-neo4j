---

## 📋 **问题背景**

### **用户洞察**

> "每个工作栏的职能不一样，导入数据肯定也不可能一样。这就要在设计阶段，提醒我们把这个部分'自动'的不能遗忘。"

### **核心问题**

1. **接口定义容易遗忘** - 开发者可能忘记定义输入/输出参数
2. **数据对接需要手动** - 工作栏之间数据传递需要手写代码
3. **缺乏强制验证** - 没有机制确保接口定义完整
4. **上传后才发现问题** - 缺失接口定义导致工作栏无法使用

---

## 🎯 **解决方案**

### **核心设计理念**

**接口定义前置** + **强制验证** + **自动提示** + **拒绝封装/上传**

```
设计阶段 → 强制定义接口 → 验证完整性 → 封装 → 上传
    ↓           ↓               ↓          ↓       ↓
  创建      填写接口      自动验证    通过验证   元数据完整
interface   definition     失败↓中止   才能封装   才能上传
  模板        文件         强制修复
```

## 📝 **1. 接口定义文件规范**

### **强制性文件：*-interface-definition.js**

每个工作栏目录必须包含此文件，文件名格式：
```
[column-name]-interface-definition.js
```

### **文件结构**

```javascript
const COLUMN_INTERFACE = {
    // ========== 基本信息 ========== ⭐ 必填
    id: 'detail',
    title: '详情页工作栏',
    version: '1.0.0',
    author: '程序员',
    description: '节点详情编辑工作栏',
    
    // ========== 输入参数 ========== ⭐ 至少1个
    inputs: [
        {
            name: 'nodeId',          // ⭐ 必填
            type: 'string',          // ⭐ 必填
            required: true,          // ⭐ 必填
            description: '节点ID',   // ⭐ 必填
            example: 'node_123',
            validation: {
                pattern: '^node_\\d+$',
                message: '节点ID格式错误'
            }
        }
    ],
    
    // ========== 输出参数 ========== ⭐ 至少1个
    outputs: [
        {
            name: 'currentNode',     // ⭐ 必填
            type: 'Object',          // ⭐ 必填
            description: '当前节点'  // ⭐ 必填
        }
    ],
    
    // ========== 触发事件 ========== ⭐ 至少1个
    events: [
        {
            name: 'node.updated',    // ⭐ 必填
            description: '节点更新', // ⭐ 必填
            payload: {}              // ⭐ 必填
        }
    ],
    
    // 依赖项、连接建议、使用示例等
    // ...
};

// ⭐ 内置自动验证
(function validateInterface() {
    // 验证逻辑
    // 如果验证失败，抛出错误
})();

// 导出
module.exports = COLUMN_INTERFACE;
```

### **验证规则**

| 规则 | 说明 | 强制性 |
|------|------|--------|
| **基本信息** | id, title, version, author, description | ✅ 必填 |
| **输入参数** | 至少定义1个输入参数 | ✅ 必填 |
| **输出参数** | 至少定义1个输出参数 | ✅ 必填 |
| **事件定义** | 至少定义1个事件 | ✅ 必填 |
| **参数完整性** | name, type, description必填 | ✅ 必填 |
| **版本格式** | semver格式（1.0.0） | ✅ 必填 |
| **ID格式** | kebab-case格式 | ✅ 必填 |

## 📦 **3. 封装脚本（内置验证）**

### **package-column.js**

**功能**：
- ⭐ **强制验证接口定义**（验证失败=中止封装）
- 内联所有 HTML/CSS/JS 文件
- 添加 IIFE 包裹
- 注入 dataInterface 配置
- 生成单文件工作栏.js

**使用方式**：

```bash
node tools/package-column.js column-sources/detail/
```

**执行流程**：

```
步骤1: 验证接口定义
  ↓
  验证失败？

  └─ 否 → 继续
```

## 🚫 **4. 强制性阻断机制**

### **封装阶段阻断**

```javascript
// package-column.js 内部

// ⭐ 强制验证接口定义
const isValid = await validator.validateColumnDirectory(this.columnDir);

if (!isValid) {
    console.error('\n❌ 接口定义验证失败！');
    console.error('❌ 封装已中止！');
    console.error('\n请修复接口定义错误后再次尝试封装。\n');
    process.exit(1);  // ⭐ 强制退出，阻止封装
}
```

### **上传阶段验证**

```javascript
// ColumnWarehouse 上传逻辑

async uploadColumn(file) {
    // 1. 解析封装后的 .js 文件
    const code = fs.readFileSync(file, 'utf-8');
    
    // 2. 提取 dataInterface
    const dataInterface = this.extractDataInterface(code);
    
    // 3. ⭐ 验证接口完整性
    if (!dataInterface) {
        throw new Error('❌ 缺少 dataInterface 定义，上传失败！');
    }
    
    if (!dataInterface.inputs || dataInterface.inputs.length === 0) {
        throw new Error('❌ 未定义输入参数，上传失败！');
    }
    
    if (!dataInterface.outputs || dataInterface.outputs.length === 0) {
        throw new Error('❌ 未定义输出参数，上传失败！');
    }
    
    // 4. 验证通过，继续上传
    // ...
}
```

## 🔄 **5. 完整工作流程**

### **开发者工作流**

```
第1步：创建工作栏目录
  mkdir column-sources/mycolumn/

第2步：复制接口定义模板
  cp column-sources/interface-definition-template.js \
     column-sources/mycolumn/mycolumn-interface-definition.js

第3步：填写接口定义 ⭐ 强制步骤
  - 填写基本信息
  - 定义输入参数（至少1个）
  - 定义输出参数（至少1个）
  - 定义触发事件（至少1个）

第4步：验证接口定义
  node tools/validate-interface.js column-sources/mycolumn/
  
  验证失败？
  ├─ 是 → 回到第3步修复
  └─ 否 → 继续

第5步：开发工作栏代码
  - mycolumn-layout.html
  - mycolumn-styles.css
  - mycolumn-core.js

第6步：封装工作栏 ⭐ 自动验证
  node tools/package-column.js column-sources/mycolumn/
  
  封装失败？
  ├─ 是 → 查看错误，回到第3步
  └─ 否 → 生成 mycolumn-column.js

第7步：上传到 ColumnWarehouse ⭐ 再次验证
  - 通过设置页面上传
  - 系统自动提取和验证接口
  - 验证失败拒绝上传

第8步：配置数据连接
  - 在 column-connections.js 中配置
  - 基于接口定义自动连接

✅ 完成！工作栏可用
```

## ✅ **6. 优势总结**

| 优势 | 说明 |
|------|------|
| **强制性** | 接口定义不完整=无法封装=无法上传 |
| **前置性** | 设计阶段就必须定义接口，无法遗忘 |
| **自动化** | 三重验证（文件验证+封装验证+上传验证） |
| **零容忍** | 任何环节验证失败都会中止流程 |
| **清晰提示** | 详细的错误信息指导修复 |
| **标准化** | 所有工作栏遵循统一的接口规范 |
| **可追溯** | 接口定义文件保留完整的设计文档 |
| **自动连接** | 基于接口定义自动配置数据流 |
