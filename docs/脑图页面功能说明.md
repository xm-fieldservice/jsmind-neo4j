## 1. 概述
本页面实现一个基于 AntV G6 TreeGraph 的项目管理脑图，可在四栏布局中与“列表/关系图/详情”协同工作。支持节点的新增、同级新增、删除、拖拽重排、复制/粘贴、折叠/展开、内联编辑与本地导入导出，并具备容器尺寸变化下的自适应缩放与居中显示能力。

---

## 2. 页面结构（`index.html`）
- 脑图容器：`#mindmap-container`
- 右键菜单：`#mindmap-contextmenu`（包含添加子/同级、编辑、删除、复制、剪切、粘贴、折叠等动作）
- 内联编辑器：`#node-editor` 与 `#node-editor-input`
- 详情面板元素：`#detail-title-input`、`#detail-content-editor`、`#detail-content-preview` 等
- 四栏布局：列表 | 脑图 | 关系图 | 详情（当前默认激活“脑图”）

---

## 3. 依赖与图形实例
- 图形库：AntV G6（TreeGraph）
- 自定义节点类型：`mind-node`（圆角长方形，文本居中，选中/拖拽/投放目标时有不同高亮与阴影）
- 图实例创建：`MindmapController.createMindmap()`
  - 交互模式：`drag-canvas`、`zoom-canvas`、`drag-node`
  - 布局：`mindmap`（水平 H 方向）
  - 事件：节点点击/双击、右键菜单、拖拽（enter/leave/end）与画布事件

---

## 4. 数据模型
- 默认数据：`defaultMindMapData`
- 本地持久化：`localStorage` Key `mindmap_data_v1`
- 辅助：
  - `findNode(nodeId)`：在树中查找节点
  - `findParentNode(nodeId)`：查找父节点
  - `clearSelectedNode()`：清除选中态

---

## 5. 核心控制器（`mindmap-controller.js`）
类：`MindmapController`

- 初始化：`init()`
  - 加载持久化 → 注册节点 → `createMindmap()` → 自适应监听 → 绑定事件/快捷键 → `renderMindmap()`
- 渲染：`renderMindmap()`
  - 首次：`graph.data()` + `graph.render()`
  - 更新：`graph.changeData()`
  - 渲染后以 `requestAnimationFrame` 批量刷新节点内容指示（若启用）
- 自适应：
  - `scheduleAutoFit(immediate=false)`：防抖缩放，限制 `minFitZoom/maxFitZoom`，配合 `fitCenter` 保持居中
  - `observeContainerResize()` / `handleContainerResize()`：容器尺寸变化时更新画布大小并触发轻微自适应

---

## 6. 节点操作
- 添加子节点：`addChildNode(parentId)`
  - 逻辑：向 `parentNode.children` 追加新节点 → `renderMindmap()` → 保存 → 选中新节点并 `editNode()`
- 添加同级节点：`addSiblingNode(nodeId)`
  - 逻辑：找到父节点与当前位置 → 在其后插入 → `renderMindmap()` → 保存 → 选中并编辑新节点
  - 限制：根节点不可添加同级
- 删除节点：`removeNode(nodeId)`
  - 逻辑：自父节点 `children` 移除，若为空则删除 `children` 字段 → `renderMindmap()` → 保存 → 选中父节点
  - 限制：根节点不可删除
- 拖拽移动/同级重排：`moveNode(sourceId, targetId, position='after')`
  - 同父级：调整顺序；跨父级：作为子节点移动到目标下
  - 完成后 `renderMindmap()`、保存、选中移动节点、`scheduleAutoFit()`
- 折叠/展开：`collapseExpandNode(nodeId)`
  - 切换 `collapsed` 并重渲染/布局

说明：当前增删/重排以“全量重绘”为主（稳定、简单）；后续可在确保兼容性的前提下恢复“优先增量 API + 失败兜底全量”的策略以提升性能。

---

## 7. 编辑与详情
- 详情面板：
  - `updateNodeDetails(nodeId)`：同步 DOM 内容与控件，支持 Markdown 预览（若 `window.marked` 可用）
  - `saveTitleFromDetail()`：更新标题，优先 `graph.updateItem()`，失败回退 `renderMindmap()`
  - `saveContentFromDetail()`：更新 `content`，优先 `graph.updateItem()`，失败回退，并刷新预览
- 内联编辑：
  - `editNode(nodeId)`：在节点上方定位输入框（透明、无边框、铺满节点），聚焦并选中文本
  - `#node-editor` 与 `#node-editor-input` 控制显示/定位

---

## 8. 右键菜单（`handleContextMenuAction`）
- 支持动作：
  - `add-child` 添加子节点
  - `add-sibling` 添加同级（根节点禁用）
  - `edit` 编辑
  - `delete` 删除（根节点禁用）
  - `copy` 复制；`cut` 剪切；`paste-child`/`paste-sibling` 粘贴
  - `collapse-toggle` 折叠/展开

---

## 9. 剪贴板与粘贴
- `copyNode(nodeId)`：深拷贝到 `this.clipboard`
- `cutNode(nodeId)`：复制后删除（根节点禁用）
- `pasteNode(targetNodeId, asChild=true)`：
  - 为整棵子树重新生成唯一 ID
  - 作为子节点或同级节点插入
  - `renderMindmap()` + 保存 + 选中新节点

---

## 10. 导入导出
- 导出：`exportMindmapToFile()`
  - 生成 `.mindmap.json`（或降级为浏览器下载）
- 导入：`importMindmapFromFile(file)` / `importMindmapFromPicker()`
  - 解析并通过 `parseAndNormalizeImported()` 规范化树结构
  - 渲染、保存并选中根节点

---

## 11. 全屏与自适应
- `toggleFullscreen()` / `exitFullscreen()`：切换容器全屏样式类，延迟 `changeSize` 与 `fitCenter`
- 自适应策略：
  - 只缩小不放大（防止少量节点被过度放大）
  - 基于容器短边计算 padding，配合 `fitCenter`

---

## 12. 边界与保护
- 根节点保护：不可同级新增、不可删除、不可剪切
- 拖拽约束：`canDragTo(sourceId, targetId)` 禁止将节点拖动到自身子树

---

## 13. 现状与优化建议
- 现状：
  - 增删/重排使用全量重绘；编辑更新优先 `updateItem()`，失败回退
  - 四栏布局切换与容器变化通过 `ResizeObserver` 触发自适应
- 建议：
  - 在 `addChildNode`、`addSiblingNode`、`removeNode`、`moveNode`、`collapseExpandNode` 中恢复“优先增量 API（`addChild/removeChild/updateItem`）+ 失败兜底全量”，并在成功后调用 `layout()` 与 `scheduleAutoFit(false)`，以提升大图场景的交互流畅度
