```javascript
openAttachment(fileUrl, fileName, fileType) {
    if (fileType.startsWith('image/')) {
        window.open(fileUrl, '_blank');  // 图片预览
    } else if (fileType === 'application/pdf') {
        window.open(fileUrl, '_blank');  // PDF查看
    } else if (fileType.startsWith('video/')) {
        window.open(fileUrl, '_blank');  // 视频播放
    } else if (fileType.startsWith('text/')) {
        window.open(fileUrl, '_blank');  // 文本查看
    } else {
        // 其他文件下载
        a.download = fileName;
        a.click();
    }
}
```

**支持的文件类型**:
- 图片：jpg, png, gif, webp → 新窗口预览
- PDF：pdf → 新窗口查看
- 视频：mp4, webm → 新窗口播放
- 文本：txt, json, md → 新窗口显示
- 其他：自动下载

#### **4.3 标签自动同步** ✅⭐

**核心创新**: 实现了标签框与内容的双向实时同步！

**方向1: 标签框 → 内容**
```
用户点击标签"重要"
      ↓
内容开头自动添加:
标签: [优先级] 重要
```

**方向2: 内容 → 标签框**
```
内容中包含:
标签: [优先级] 重要
标签: [状态] 进行中
      ↓
标签框自动显示:
"重要"和"进行中"为选中状态
```

**实现机制**:
```javascript
// 解析内容中的标签
syncTagsFromContent() {
    const lines = content.split('\n');
    const tagsInContent = new Set();
    
    for (const line of lines) {
        const match = line.match(/^标签:\s*\[([^\]]+)\]\s*(.+)$/);
        if (match) {
            const tags = match[2].split(',').map(t => t.trim());
            tags.forEach(tag => tagsInContent.add(tag));
        }
    }
    
    // 同步到标签框
    chips.forEach(chip => {
        if (tagsInContent.has(chip.dataset.tag)) {
            chip.classList.add('active');
        }
    });
}
```

**防抖优化**:
- 输入内容时，延迟500ms后才同步
- 避免频繁更新，提升性能
