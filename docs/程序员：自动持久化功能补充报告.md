## 🎯 **ColumnAutoPersistence 核心机制**

### **架构设计**

```
工作栏数据变化
  ↓
触发事件: column.dataChanged
  ↓
ColumnAutoPersistence 监听
  ↓
防抖1秒 + 定时5秒
  ↓
AutogenUnifiedStorage.store()
  ↓
分层存储:
  ├─ 内存缓存（立即）
  ├─ LocalStorage（<5MB）
  └─ IndexedDB（>5MB）
  ↓
触发事件: column.dataSaved
  ↓
✅ 持久化完成

页面刷新后:
  ↓
ColumnAutoPersistence.restoreColumnData()
  ↓
触发事件: column.dataRestored
  ↓
工作栏恢复UI
  ↓
✅ 数据完整恢复
```

## 💻 **工作栏接入方式（极简）**

### **步骤1: 定义数据结构**
```javascript
this.columnId = 'your-column';
this.data = { field1: '', field2: [] };
```

### **步骤2: 监听恢复事件（5行）**
```javascript
window.AutogenEventBus.on('column.dataRestored', (event) => {
    if (event.columnId === this.columnId) {
        this.loadData(event.data);
    }
});
```

### **步骤3: 触发保存事件（5行）**
```javascript
notifyDataChanged() {
    window.AutogenEventBus.emit('column.dataChanged', {
        columnId: this.columnId,
        data: this.data
    });
}

// 在数据变化时调用
input.addEventListener('input', () => {
    this.data.field = value;
    this.notifyDataChanged();  // 触发保存
});
```

**总代码量**: 10行核心代码  
**接入时间**: 5分钟
