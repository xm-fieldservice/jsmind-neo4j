## 1️⃣ **列表栏评估** ⭐ 简单

### **当前功能分析**

**主要功能**：
```
✅ 项目统计（总项目数、存储模式）
✅ 项目列表展示
✅ 查询结果展示
✅ 日志面板（可折叠）
✅ 测试按钮（MD保存、清空、复制）
```

**代码位置**：
- HTML: `index.html` 第126-184行
- CSS: `project_list_styles.css`
- JS: `list_tag_filter.js`, `tag_list_filter_enhancement.js`

### **能否被泳道工作栏替代？**

✅ **完全可以替代！**

**理由**：
1. **功能重叠90%**：
   - 列表栏：项目列表展示
   - 泳道工作栏：项目列表 + 状态分组展示（更强）
   
2. **泳道工作栏优势**：
   - ✅ 按状态分组（待开始/进行中/已完成）
   - ✅ 按部门分组
   - ✅ 拖拽调整状态
   - ✅ 更好的可视化效果

3. **不会丢失功能**：
   - 项目统计 → 泳道看板也可以显示
   - 日志面板 → 可保留在工作区或设置栏

### **改造方案**

#### **方案A：完全替换（推荐）** ⏱️ 0.5天
```
1. 删除列表栏HTML（第126-184行）
2. 删除相关CSS文件
3. 泳道工作栏默认上线
4. 数据接口对接项目列表数据源
```

#### **方案B：保留并存** ⏱️ 1天
```
1. 将列表栏改造为工作栏
2. 与泳道看板并存
3. 用户可选择使用哪个
```

**推荐**: **方案A - 完全替换**

3. **接口清晰**：
   - 输入：节点数据
   - 输出：关系可视化
   - 事件：节点选中、关系查看

### **改造方案**

#### **Step 1: 提取代码** ⏱️ 2小时
```
1. 复制关系栏HTML结构

4. 提取D3.js渲染代码
```

#### **Step 2: 封装为工作栏** ⏱️ 2小时
```javascript
// relation-graph.js
ColumnRegistry.register({
    id: 'relation-graph',
    title: '关系图谱',
    icon: '🔗',
    
    renderFn: (container) => {
        // 渲染关系图UI
        container.innerHTML = `
            <div class="relation-container">
                <!-- 工具栏 -->
                <!-- 关系列表 -->
                <!-- D3.js可视化区域 -->
            </div>
        `;
        
        // 初始化D3.js
        initD3RelationGraph(container);
        
        // 绑定事件

    },
    
    dataInterface: {
        inputs: [

            { name: 'relations', type: 'Array', description: '关系数据' }
        ],
        outputs: [
            { name: 'selectedRelation', type: 'Object', description: '选中的关系' }
        ],
        events: [
            'relation.nodeSelected',
            'relation.syncToNeo4j'
        ]
    }
```
