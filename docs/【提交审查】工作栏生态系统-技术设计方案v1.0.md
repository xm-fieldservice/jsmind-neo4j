### 3.1 工作栏规范定义

**文档**: `docs/工作栏开发规范v1.0.md`

#### 3.1.1 标准结构

```javascript
/**
 * 工作栏模块规范 v1.0
 */
const WorkColumnSpec = {
    // 元数据
    meta: {
        id: 'swimlane',              // 必填：唯一标识
        name: '泳道看板',             // 必填：显示名称
        version: '1.0.0',            // 必填：版本号
        author: 'Your Team',         // 可选：作者
        description: '多维度任务看板', // 可选：描述
        icon: '🏊'                   // 可选：图标
    },
    
    // 依赖声明
    dependencies: {
        system: ['AutogenUnifiedStorage', 'AutogenEventBus'],
        external: []  // 外部库，如 ['sortablejs']
    },
    
    // 生命周期钩子
    lifecycle: {
        init: function() {},           // 初始化
        mount: function(container) {}, // 挂载
        unmount: function() {},        // 卸载
        destroy: function() {}         // 销毁
    },
    
    // 事件声明
    events: {
        subscribe: ['project:updated'],  // 订阅事件
        publish: ['swimlane:taskMoved']  // 发布事件
    },
    
    // 配置项
    config: {
        defaultActive: false,
        position: 'after:list',
        icon: '🏊'
    }
};
```

### 3.2 泳道看板封装

**源文件**: `test_department_list_container.html`  
**目标文件**: `columns/swimlane-column.js`

#### 3.2.1 封装方案

**提取内容**：
1. HTML结构（内联到JS中）
2. CSS样式（内联到JS中）
3. JavaScript逻辑（封装为模块）
4. 数据接口（对接AutogenUnifiedStorage）

**封装结构**：
```javascript
(function() {
    'use strict';
    
    const SwimlaneColumn = {
        meta: {
            id: 'swimlane',
            name: '泳道看板',
            version: '1.0.0',
            author: 'Project Team',
            description: '多维度任务泳道看板',
            icon: '🏊'
        },
        
        dependencies: {
            system: ['AutogenUnifiedStorage', 'AutogenEventBus'],
            external: []
        },
        
        state: {
            currentDimension: 'status',
            projects: [],
            container: null
        },
        
        lifecycle: {
            init() {
                // 初始化逻辑
            },
            mount(container) {
                // 挂载逻辑：注入HTML、加载数据、渲染
            },
            unmount() {
                // 卸载逻辑：清理事件监听
            },
            destroy() {
                // 销毁逻辑：释放资源
            }
        }
    };
    
    // 注册到全局
    window.SwimlaneColumn = SwimlaneColumn;
    
    // 自动注册到ColumnRegistry
    if (window.ColumnRegistry) {
        window.ColumnRegistry.register({
            id: SwimlaneColumn.meta.id,
            title: SwimlaneColumn.meta.name,
            icon: SwimlaneColumn.meta.icon,
            position: 'after:list',
            defaultActive: false,
            renderFn: (container) => {
                SwimlaneColumn.lifecycle.init();
                SwimlaneColumn.lifecycle.mount(container);
            }
        });
    }
})();
```

## 📝 技术决策记录

### 决策1：使用eval()执行工作栏代码

**背景**：需要动态执行上传的工作栏代码  
**方案**：使用Function构造器替代eval()  
**理由**：提供一定的隔离，降低安全风险  
**风险**：仍存在代码注入风险  
**缓解**：添加代码审查机制

### 决策2：使用localStorage存储工作栏

**背景**：需要持久化工作栏代码和配置  
**方案**：localStorage + 压缩  
**理由**：简单直接，无需后端  
**风险**：配额限制（~5MB）  
**缓解**：添加配额检查和清理机制
