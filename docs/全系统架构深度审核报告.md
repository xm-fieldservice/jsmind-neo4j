**解决方案**:

- 集成或删除未使用文件
- 统一数据管理器接口

#### **3.2 控制台日志标准化 (优先级: 低)**

**问题**: 混用传统console.log和统一日志系统
```javascript
// 发现: 49个文件中仍有大量console.log调用
// 示例: console.log('[D3关系图] 初始化可视化组件');
// 影响: 日志管理不统一，难以集中监控
```

**解决方案**:
- 启用LoggerMigrationTool控制台拦截
- 逐步迁移关键模块到统一日志
- 建立日志规范检查工具

#### **3.3 笔记功能架构集成 (优先级: 低)**

**问题**: 笔记功能直接在index.html中实现
```javascript
// 发现位置: index.html:668-699
// 问题: 业务逻辑混入HTML，违反分层原则
// 影响: 可维护性差，难以测试和扩展
```

**解决方案**:
- 提取笔记功能到独立模块
- 集成到业务层架构
- 使用统一存储服务

#### **3.4 全局变量依赖优化 (优先级: 中)**

**问题**: 仍存在61个文件使用window/global访问
```javascript
// 统计结果: 61个文件，约200+处全局访问
// 主要模式: window.jsMind, window.AutogenEventBus, global.UnifiedLogger
// 影响: 模块耦合度高，测试困难
```

**解决方案**:
- 扩展DependencyContainer覆盖范围
- 实现模块级依赖注入
- 建立全局变量使用规范
