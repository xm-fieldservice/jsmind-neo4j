# 🔔 **提示词强制执行机制**

## 🎯 **解决AI提示词遗忘症的根本方案**

### **问题分析**
AI在执行过程中会逐渐遗忘提示词约束，特别是：
- 第2条："是否最大限度使用了当前框架内原生的组件和功能"
- 第3条："是否随意的生成了重复的自定义方法和代码"
- 第4条："是否不顾已有的代码和方法，重复造轮子"

### **机制3: 自动提示词回忆**
```javascript
// AI执行过程中的强制回忆机制
class PromptEnforcer {
    constructor() {
        this.constraints = [
            "最大限度使用当前框架内原生的组件和功能",
            "不得随意生成重复的自定义方法和代码", 
            "不得重复造轮子",
            "必须逐行代码分析",
            "功能重叠度必须量化"
        ];
    }
    
    // 每50行代码强制回忆
    enforceConstraints(codeLines) {
        if (codeLines % 50 === 0) {
            console.log("🔔 强制回忆提示词约束：");
            this.constraints.forEach((c, i) => {
                console.log(`${i+1}. ${c}`);
            });
            
            this.performMandatoryCheck();
        }
    }
    
    performMandatoryCheck() {
        const questions = [
            "我是否查询了框架原生功能？",
            "我是否重复实现了已有功能？", 
            "我是否遵循了逐行分析要求？",
            "当前功能重叠度是多少？"
        ];
        
        questions.forEach(q => {
            console.log(`❓ 必答: ${q}`);
        });
    }
}
```
