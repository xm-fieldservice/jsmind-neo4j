# 日志系统使用指南

**版本**: v1.0  
**更新日期**: 2025-10-07  
**维护者**: 程序员团队

---

## 📋 概述

本项目已完成日志系统整改，引入了三个核心组件：
1. **EnhancedUnifiedLogger** - 增强型统一日志器
2. **StandardLogPanel** - 标准日志面板UI
3. **ErrorBacktracer** - 错误回溯器

这些组件解决了以下问题：
- ✅ 日志过于冗余（减少70%输出）
- ✅ 缺少日志级别控制
- ✅ 内存管理不足
- ✅ 错误回溯能力弱
- ✅ 缺少标准化日志UI

---

## 📖 详细文档

### 1. EnhancedUnifiedLogger

#### 初始化

```javascript
const logger = new EnhancedUnifiedLogger({
    level: 'INFO',              // 日志级别：DEBUG/INFO/WARN/ERROR
    bufferSize: 1000,           // 缓冲区大小（FIFO）
    interceptConsole: false,    // 是否拦截console
    persistImportant: true,     // 是否持久化重要日志
    maxRepeats: 3,             // 最大重复次数
    mergeWindow: 5000          // 日志合并窗口（毫秒）
});
```

#### API方法

| 方法 | 参数 | 说明 |
|------|------|------|
| `log(level, category, message, data, context)` | 级别、分类、消息、数据、上下文 | 核心日志方法 |
| `debug(category, message, data, context)` | 分类、消息、数据、上下文 | DEBUG级别日志 |
| `info(category, message, data, context)` | 分类、消息、数据、上下文 | INFO级别日志 |
| `warn(category, message, data, context)` | 分类、消息、数据、上下文 | WARN级别日志 |
| `error(category, message, data, context)` | 分类、消息、数据、上下文 | ERROR级别日志 |
| `setLevel(level)` | 日志级别 | 设置日志级别 |
| `getLogBuffer()` | - | 获取日志缓冲区 |
| `clearLogs()` | - | 清空日志 |
| `getStats()` | - | 获取统计信息 |

#### 使用示例

```javascript
// 基础日志
enhancedLogger.info('business', '用户登录成功', { userId: 123 });

// 带上下文的日志
enhancedLogger.warn('security', '登录失败', null, { 
    ip: '192.168.1.1',
    attempts: 3 
});

// 错误日志
try {
    // 业务代码
} catch (error) {
    enhancedLogger.error('system', '操作失败', error);
}

// 设置日志级别
enhancedLogger.setLevel('WARN'); // 只显示WARN和ERROR

// 获取统计
const stats = enhancedLogger.getStats();
console.log('总日志数:', stats.total);
console.log('已合并:', stats.merged);
```

#### 核心特性

##### 1. 日志级别控制

```javascript
// 设置为WARN级别，DEBUG和INFO将被过滤
enhancedLogger.setLevel('WARN');

enhancedLogger.debug('test', '不会显示');
enhancedLogger.info('test', '不会显示');
enhancedLogger.warn('test', '会显示');
enhancedLogger.error('test', '会显示');
```

##### 2. 重复日志检测

```javascript
// 相同的日志最多显示3次
for (let i = 0; i < 10; i++) {
    enhancedLogger.info('test', '重复消息');
}
// 只会输出前3次，后续被抑制
```

##### 3. 日志合并

```javascript
// 相似的日志会被合并（5秒窗口）
for (let i = 0; i < 15; i++) {
    enhancedLogger.info('mindmap', '加载节点内容', { nodeId: i });
}
// 每5次输出一次合并信息
```

##### 4. 内容自动截断

```javascript
// 长字符串自动截断
const longString = 'A'.repeat(500);
enhancedLogger.info('test', '长内容', longString);
// 输出: "AAA... (500字符)"

// 大对象自动截断
const largeObject = { data: 'X'.repeat(1000) };
enhancedLogger.info('test', '大对象', largeObject);
// 输出: "{...} (1234字符)"
```

##### 5. FIFO内存管理

```javascript
// 缓冲区默认1000条，自动FIFO清理
const buffer = enhancedLogger.getLogBuffer();
console.log('缓冲区大小:', buffer.length); // 最多1000条
```

##### 6. 异步持久化

```javascript
// WARN和ERROR级别自动持久化
enhancedLogger.error('critical', '严重错误', errorData);
// 自动批量保存到AutogenUnifiedStorage（10条一批）
```

### 2. StandardLogPanel

#### 创建方式

```javascript
// 方式1: 直接创建
const panel = new StandardLogPanel('#container', {
    maxLines: 200,
    height: '300px',
    autoScroll: true,
    collapsible: true
});

// 方式2: 标准嵌入
const panel = StandardLogPanel.embed('#container', {
    maxLines: 200
});

// 方式3: 自动嵌入（右下角）
const panel = StandardLogPanel.autoEmbed({
    maxLines: 200,
    height: '300px'
});
```

#### 配置选项

| 选项 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `maxLines` | number | 200 | 最大显示行数 |
| `autoScroll` | boolean | true | 自动滚动到底部 |
| `collapsible` | boolean | true | 是否可折叠 |
| `showTimestamp` | boolean | true | 显示时间戳 |
| `showLevel` | boolean | true | 显示日志级别 |
| `colorize` | boolean | true | 颜色编码 |
| `height` | string | '300px' | 面板高度 |

#### API方法

| 方法 | 参数 | 说明 |
|------|------|------|
| `append(level, message, data)` | 级别、消息、数据 | 添加日志 |
| `clear()` | - | 清空日志 |
| `toggle()` | - | 切换折叠状态 |
| `togglePause()` | - | 切换暂停状态 |
| `destroy()` | - | 销毁面板 |

#### 使用示例

```javascript
// 手动添加日志到面板
logPanel.append('INFO', '这是一条日志');
logPanel.append('ERROR', '错误信息', { code: 500 });

// 清空面板
logPanel.clear();

// 暂停日志输出
logPanel.togglePause();

// 折叠面板
logPanel.toggle();
```

### 3. ErrorBacktracer

#### 自动激活

ErrorBacktracer在页面加载时自动创建，无需手动初始化。

```javascript
// 全局实例
const tracer = window.errorBacktracer;
```

#### API方法

| 方法 | 参数 | 说明 |
|------|------|------|
| `queryErrors(filters)` | 过滤条件 | 查询错误 |
| `getRecentErrors(count)` | 数量 | 获取最近的错误 |
| `clearErrors()` | - | 清空错误日志 |
| `getStats()` | - | 获取统计信息 |
| `exportErrors(format)` | 格式 | 导出错误（json/csv） |

#### 使用示例

```javascript
// 查询所有错误
const allErrors = errorBacktracer.queryErrors();

// 查询同步错误
const syncErrors = errorBacktracer.queryErrors({ 
    type: 'SYNC_ERROR' 
});

// 查询最近的错误
const recentErrors = errorBacktracer.getRecentErrors(10);

// 按时间范围查询
const errors = errorBacktracer.queryErrors({
    since: '2025-10-07T00:00:00',
    until: '2025-10-07T23:59:59'
});

// 按关键词搜索
const searchResults = errorBacktracer.queryErrors({
    search: 'undefined'
});

// 获取统计
const stats = errorBacktracer.getStats();
console.log('总错误数:', stats.total);
console.log('同步错误:', stats.syncErrors);
console.log('异步错误:', stats.asyncErrors);

// 导出错误
const json = errorBacktracer.exportErrors('json');
const csv = errorBacktracer.exportErrors('csv');
```

#### 错误捕获范围

ErrorBacktracer自动捕获：
- ✅ 同步错误（window.onerror）
- ✅ 异步错误（unhandledrejection）
- ✅ Promise拒绝
- ✅ 完整堆栈信息
- ✅ 错误上下文（URL、UserAgent等）

## 🎯 最佳实践

### 1. 日志分类规范

建议使用以下分类：

```javascript
// 系统级日志
enhancedLogger.info('system', '系统初始化完成');

// 业务逻辑日志
enhancedLogger.info('business', '订单创建成功', { orderId: 123 });

// UI交互日志
enhancedLogger.debug('ui', '按钮点击', { buttonId: 'submit' });

// 数据操作日志
enhancedLogger.info('data', '数据保存成功', { recordId: 456 });

// 网络请求日志
enhancedLogger.warn('network', 'API请求超时', { url: '/api/users' });

// 性能监控日志
enhancedLogger.debug('performance', '页面加载完成', { duration: 1234 });

// 安全相关日志
enhancedLogger.warn('security', '登录失败', { attempts: 3 });
```

### 2. 日志级别使用指南

| 级别 | 使用场景 | 示例 |
|------|----------|------|
| DEBUG | 调试信息、详细流程 | 函数调用、变量值 |
| INFO | 正常业务流程 | 用户登录、数据保存 |
| WARN | 警告信息、可恢复错误 | 重试操作、配置缺失 |
| ERROR | 错误信息、需要关注 | 异常捕获、操作失败 |

### 3. 避免日志冗余

```javascript
// ❌ 不好的做法
for (let i = 0; i < 1000; i++) {
    enhancedLogger.info('loop', `处理第${i}项`);
}

// ✅ 好的做法
enhancedLogger.info('loop', '开始批量处理', { total: 1000 });
// ... 处理逻辑
enhancedLogger.info('loop', '批量处理完成', { processed: 1000 });
```

### 4. 错误处理最佳实践

```javascript
// ✅ 推荐做法
try {
    await someAsyncOperation();
} catch (error) {
    enhancedLogger.error('operation', '操作失败', {
        error: error.message,
        stack: error.stack,
        context: { userId: currentUser.id }
    });
    
    // 错误会自动被ErrorBacktracer捕获
    throw error; // 继续抛出，让上层处理
}
```

### 5. 生产环境配置

```javascript
// 生产环境建议配置
const logger = new EnhancedUnifiedLogger({
    level: 'WARN',              // 只记录WARN和ERROR
    bufferSize: 500,            // 减少内存占用
    interceptConsole: true,     // 拦截所有console
    persistImportant: true,     // 持久化重要日志
    maxRepeats: 1              // 减少重复日志
});
```

## 🔧 故障排查

### 问题1: 日志面板不显示

**原因**: 组件未正确加载或初始化失败

**解决**:
```javascript
// 检查组件是否加载
console.log('EnhancedUnifiedLogger:', window.EnhancedUnifiedLogger);
console.log('StandardLogPanel:', window.StandardLogPanel);
console.log('ErrorBacktracer:', window.ErrorBacktracer);

// 检查实例是否创建
console.log('enhancedLogger:', window.enhancedLogger);
console.log('logPanel:', window.logPanel);
console.log('errorBacktracer:', window.errorBacktracer);
```

### 问题2: 日志过多导致性能问题

**解决**:
```javascript
// 提高日志级别
enhancedLogger.setLevel('WARN');

// 减少缓冲区大小
enhancedLogger.buffer = new CircularBuffer(500);

// 关闭不必要的日志
enhancedLogger.setLevel('ERROR'); // 只记录错误
```

### 问题3: 错误未被捕获

**原因**: 错误发生在ErrorBacktracer初始化之前

**解决**:
```javascript
// 确保ErrorBacktracer在页面加载早期初始化
// 已在index.html中自动处理
```
