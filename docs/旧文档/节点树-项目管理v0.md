# 节点树-项目管理v0 功能说明文档

## 1. 系统概述

节点树项目管理系统是一个基于jsMind脑图技术与Neo4j图数据库的项目管理工具，专注于节点化的项目内容组织与关系管理。系统采用四栏布局设计，整合了列表视图、脑图视图、关系图和节点详情功能，提供直观且高效的项目管理体验。

### 1.2 技术栈

- **前端**：原生JavaScript、HTML5、CSS3、jsMind库
- **后端**：Python、FastAPI
- **数据库**：Neo4j图数据库
- **数据交换**：JSON格式
- **本地存储**：LocalStorage、IndexedDB

## 2. 核心功能模块

### 2.1 用户界面（UI）层

#### 2.1.1 四栏布局

系统采用四栏并列布局，各栏功能明确：

- **列表栏**：项目节点的扁平化列表视图
- **脑图栏**：基于jsMind的层级化脑图展示
- **关系栏**：基于Neo4j的节点关系可视化
- **详情栏**：当前选中节点的详细信息与编辑界面

#### 2.1.2 导航系统

- **顶部导航栏**：提供视图切换、保存、设置和帮助功能
- **视图切换**：可在四栏视图、列表视图、脑图视图和详情视图间切换
- **状态栏**：显示当前选中节点信息和同步状态

### 2.2 数据层

#### 2.2.1 `mindData.js` - 核心数据结构

- **功能**：提供脑图数据的增删改查和转换操作
- **关键方法**：
  - `findNode(id)`: 按ID查找节点
  - `findParentNode(id)`: 查找父节点
  - `convertToJsMindTree()`: 数据格式转换
  - `getNodePath(id)`: 获取节点路径

#### 2.2.2 `mindmapStorage.js` - 数据持久化

- **功能**：负责脑图数据在localStorage和IndexedDB间的存取和同步
- **关键方法**：
  - `saveMindmap(data)`: 保存脑图数据
  - `loadMindmap()`: 加载脑图数据
  - `getVersions()`: 获取历史版本
  - `exportToFile(format)`: 导出脑图文件

### 2.3 控制器层

#### 2.3.1 `jsmind-controller.js` - 脑图控制器

- **功能**：管理jsMind实例、处理用户交互和UI更新
- **关键方法**：
  - `init()`: 初始化控制器和jsMind实例
  - `createMind()`: 创建新脑图
  - `selectNode(id)`: 选中节点
  - `addNode(parent_id, topic)`: 添加新节点
  - `removeNode(id)`: 删除节点
  - `saveContentFromDetail()`: 保存节点详情内容

#### 2.3.2 `script.js` - 主应用逻辑

- **功能**：管理全局UI布局、视图切换、查询和关系显示
- **关键类**：
  - `ColumnManager`: 控制四栏布局的显示和尺寸
  - `HotReload`: 监控文件变化并自动刷新

### 2.4 后端服务

#### 2.4.1 `main.py` - API接口

- **功能**：提供REST API端点处理关系数据
- **关键端点**：
  - `GET /api/relations`: 获取节点关系
  - `POST /api/relations`: 创建新关系
  - `POST /api/sync-mindmap`: 同步脑图数据到Neo4j

#### 2.4.2 `extractors.py` - 关系提取器

- **功能**：从脑图数据提取结构化关系
- **关键方法**：
  - `extract_relationships()`: 提取节点层级和引用关系

#### 2.4.3 `database.py` - 数据库连接

- **功能**：管理Neo4j数据库连接
- **关键功能**：提供Neo4j连接驱动实例

## 3. 功能详解

### 3.1 项目列表功能

#### 3.1.1 列表视图组件

- **项目搜索**：支持实时搜索过滤项目列表
- **状态标记**：通过标签直观显示项目状态（进行中、已完成、未开始等）
- **排序筛选**：按名称、状态、优先级等进行排序和筛选
- **快速操作**：提供添加、刷新和筛选按钮

#### 3.1.2 数据交互

- **与脑图同步**：列表视图与脑图视图数据同步
- **选择联动**：在列表中选择项目会在脑图中高亮相应节点

### 3.2 脑图功能

#### 3.2.1 脑图视图组件

- **节点操作**：
  - 添加子节点（Tab）
  - 添加同级节点（Enter）
  - 删除节点（Delete）
  - 节点编辑（双击或F2）
  
- **导航控制**：
  - 缩放功能（放大/缩小/适应屏幕）
  - 节点拖拽
  - 节点折叠/展开

- **批量操作**：
  - 复制节点（Ctrl+C）
  - 剪切节点（Ctrl+X）
  - 粘贴节点（Ctrl+V）

#### 3.2.2 脑图工具栏

提供脑图常用操作的快捷按钮，包括：
- 全屏模式
- 导出/导入脑图
- 创建新脑图
- 节点操作（添加、删除、编辑）
- 缩放控制

#### 3.2.3 右键菜单

提供丰富的上下文操作，包含：
- 添加子/同级节点
- 编辑节点
- 复制/剪切/粘贴
- 删除节点

### 3.3 关系图功能

#### 3.3.1 关系可视化

- **图形展示**：通过SVG展示节点之间的关系图
- **交互控制**：支持拖拽、缩放和点击选择
- **样式区分**：不同类型的关系使用不同的线条样式

#### 3.3.2 关系管理

- **关系筛选**：按方向（出边/入边）和关系类型筛选
- **关系列表**：显示当前节点的所有关系
- **关系操作**：提供编辑和删除关系的功能
- **同步功能**：将脑图结构同步到Neo4j数据库

#### 3.3.3 数据交互

- **Neo4j集成**：与Neo4j图数据库的双向数据交换
- **关系查询**：支持基于Cypher的自定义查询
- **路径分析**：提供节点间的路径分析功能

### 3.4 节点详情功能

#### 3.4.1 基本信息

- **标题编辑**：修改节点标题
- **节点ID**：显示唯一标识
- **状态管理**：更改节点状态和完成进度

#### 3.4.2 内容编辑

- **Markdown编辑器**：支持Markdown格式编辑节点内容
- **实时预览**：切换查看Markdown渲染效果
- **自动保存**：编辑内容后自动保存或手动触发保存

#### 3.4.3 附件管理

- **文件上传**：支持添加各类文件作为附件
- **附件列表**：展示所有附件及其类型
- **快速操作**：提供查看和删除附件的功能

#### 3.4.4 标签系统

- **标签组**：分类管理标签（常用标签、状态、优先级、类型）
- **标签选择**：为节点添加或移除标签
- **自定义样式**：标签支持自定义颜色和样式

#### 3.4.5 查询功能

详情面板提供三种查询选项卡：
- **相关节点查询**：按关系类型、节点属性等查询相关节点
- **路径分析**：分析当前节点与目标节点间的路径
- **自定义Cypher查询**：支持编写自定义Neo4j Cypher查询语句

## 4. 用户交互流程

### 4.1 项目创建与浏览

1. 通过顶部导航栏或列表面板的"添加"按钮创建新项目
2. 在列表面板浏览现有项目
3. 点击项目进入详细视图
4. 通过搜索框过滤项目列表

### 4.2 脑图节点管理

1. 在脑图面板创建根节点（新建脑图）
2. 使用Tab键添加子节点
3. 使用Enter键添加同级节点
4. 双击节点编辑标题
5. 拖拽节点调整层级结构
6. 右键节点访问更多操作

### 4.3 节点详情编辑

1. 在脑图中选择节点，在详情面板查看信息
2. 编辑节点标题、状态和内容
3. 添加或移除标签
4. 上传或管理附件
5. 点击保存按钮或自动保存更改

### 4.4 关系管理

1. 在脑图中选择节点，查看关系面板
2. 筛选显示特定关系类型
3. 创建新关系（从选中节点到其他节点）
4. 编辑或删除已有关系
5. 点击"同步"按钮将脑图结构同步到Neo4j

### 4.5 数据导入导出

1. 点击脑图工具栏的"导出"按钮导出脑图数据
2. 点击"导入"按钮从文件加载脑图
3. 使用"同步"功能将数据同步到Neo4j
4. 在详情面板导出特定节点的内容

## 5. 技术实现细节

### 5.1 数据流向

#### 5.1.1 节点数据流向

```
用户交互 -> jsmind-controller.js -> mindData.js -> mindmapStorage.js -> localStorage/IndexedDB
                     |                                    ^
                     v                                    |
              UI更新(script.js)                   数据加载(初始化)
```

#### 5.1.2 关系数据流向

```
脑图节点选择 -> script.js -> 后端API(/api/relations) -> extractors.py -> database.py -> Neo4j
                  ^                    |
                  |                    v
               UI更新(关系列表)    <-  JSON响应
```

#### 5.1.3 同步流程

```
"同步"按钮点击 -> script.js -> 后端API(/api/sync-mindmap) -> extractors.py -> 
                                                             提取关系 -> 
                                                             存储到Neo4j ->
                                                             返回统计结果
```

### 5.2 存储机制

- **本地持久化**：使用localStorage和IndexedDB存储脑图数据
- **文件导出**：支持JSON格式脑图数据导出
- **图数据库**：使用Neo4j存储节点关系数据
- **版本管理**：支持脑图数据的历史版本保存和恢复

### 5.3 性能优化

- **延迟加载**：大型脑图采用部分加载策略
- **本地缓存**：频繁访问的数据保存在本地存储
- **增量更新**：仅同步已变更的节点和关系
- **节点渲染优化**：使用高效的DOM操作策略

## 7. 故障排除与常见问题

### 7.1 已知问题

- **拖拽状态问题**：特定情况下节点拖拽状态可能异常
- **内容保存同步**：节点内容保存与数据同步偶有延迟
- **关系显示限制**：大量关系的可视化性能有限制

### 7.2 解决方案

- **拖拽修复**：使用`fix_drag_state.js`修复拖拽问题
- **持久化改进**：使用`fix-persistence-issues.js`增强数据同步
- **调试工具**：使用`debug-console.js`和`debug-mindmap.js`进行问题诊断

## 9. 结论

节点树项目管理系统通过整合脑图和图数据库技术，提供了一个直观、高效的项目管理解决方案。四栏布局设计使得用户可以从不同角度和层次管理项目内容，脑图提供层次化的结构化视图，而Neo4j图数据库则支持复杂的关系查询和分析。系统的模块化架构设计使得各组件职责明确，便于维护和扩展。

随着系统的持续发展，将进一步增强数据分析、协作编辑和跨平台支持等能力，为项目管理提供更全面的工具支持。
