# MD 阅读器全屏与会话增强需求文档

## 1. 背景
在节点详情的内容框（Markdown 阅读/编辑区域）基础上，增加“全屏编辑”和“会话分段管理”能力，以提升长文与多段内容编辑效率，并保持与现有持久化机制和标签/Emoji 联动的稳定性。

## 2. 目标
- 提供全屏级别（宽度增强 x3，等高）的编辑体验，同时保持小屏自适应。
- 在全屏模式下支持“会话列表”与“新增会话”的大纲式编辑流程。
- 提供常用 Markdown 工具栏按钮，提升编辑效率。
- 与原内容框双向同步，关闭全屏后自动持久化保存。

## 3. 术语
- 内容框：节点详情中的现有 `textarea` 编辑区域。
- 全屏框：进入全屏模式后出现的主编辑区域（左侧）。
- 会话列表：全屏模式下，原内容框位置显示的右侧会话列表区域。
- 段落分隔符：用于切分会话的统一标识，采用 `\n\n---\n\n`。
- 会话头部：每段会话的标题行，格式为 `### 会话 yyyy-MM-dd HH:mm:ss`。

## 4. 功能需求
- 全屏按钮：
  - 出现在内容框工具区；点击后进入全屏模式。
  - 全屏框高度 = 当前内容框高度；宽度 = 当前内容框 3 倍。
  - 最大宽度限制：不超过视口宽度 95%，小屏时自适应。
- 退出全屏：
  - 关闭按钮或 ESC 关闭；关闭后恢复原布局。
  - 全屏内容同步回原内容框并触发保存（沿用现有防抖/失焦策略）。
- 会话列表：
  - 显示在全屏模式右侧，占用原内容框的位置。
  - 顶部包含“新增会话”按钮。
  - 自动解析当前全屏内容为多段，按分隔符切片；用每段首个非空行为标题。
  - 若首行不是 `###` 标题，则自动补一个 `### 会话 yyyy-MM-dd HH:mm:ss` 作为标题。
  - 点击任一会话项，左侧全屏框滚动并将光标定位到该会话头部。
- 新增会话：
  - 在光标处（无选区则在内容尾部）插入：`\n\n---\n\n### 会话 yyyy-MM-dd HH:mm:ss\n\n`。
  - 自动添加时间戳并将光标置于新会话标题后的空行，等待输入。
- 全屏编辑：
  - 支持对全局内容进行自由编辑与浏览，不局限于单一会话。

## 5. Markdown 工具栏（作用域：全屏内容区）
- 标题 H1~H6：在当前行首插入 `#`~`######`。
- 分隔符：插入 `\n\n---\n\n`。
- 加粗：包裹选区为 `**文本**`；无选区插入模板 `**粗体**` 并选中“粗体”。
- 斜体：`*文本*`；无选区插入 `*斜体*`。
- 删除线：`~~文本~~`；无选区插入 `~~删除线~~`。
- 列表：
  - 无序列表：在行首插入 `- `。
  - 有序列表：在行首插入 `1. `。
- 任务清单：在行首插入 `- [ ] `。
- 引用：在行首插入 `> `。
- 行内代码：包裹为 `` `文本` ``；代码块为三反引号包裹（可选语言）。
- 链接/图片模板：`[标题](url)` / `![描述](url)`（可后续阶段实现）。
- 字体大小：仅影响全屏编辑区 textarea 的字号（放大/缩小/重置）。
- 复制：优先复制选中文本，否则复制全文。
- 粘贴：读取剪贴板文本并在光标处插入；若权限受限给出中文提示。

## 6. 布局与样式
- 进入全屏：区域采用左右分栏：
  - 左：全屏框（主编辑区，宽度=原内容框 3x，最大 95vw），含工具栏 + 编辑区。
  - 右：会话列表（在原内容框位置），顶部“新增会话”按钮，列表可滚动。
- 退出全屏：恢复为原单列内容框布局。
- 样式类名建议：
  - `.mm-fullscreen-wrap`（全屏根容器）
  - `.mm-editor-pane`（左侧编辑区容器）
  - `.mm-session-list`（右侧会话列表容器）
  - `.mm-toolbar`（工具栏）
  - `.mm-editor`（textarea 编辑器）

## 7. 同步与持久化
- 打开全屏：从 `dom.contentEditor.value` 载入当前内容。
- 关闭全屏：将全屏内容写回 `dom.contentEditor.value`，并调用现有保存函数 `saveContentFromDetail()` 或触发已存在的防抖保存；遵循“空值不覆盖”的占位策略。
- 保持与现有标签/Emoji 逻辑兼容，不改变内容结构以外的行为。

## 8. 快捷键
- 打开全屏：`F` 或 `Alt+Enter`。
- 关闭全屏：`ESC`。
- 保存并关闭：`Ctrl+Enter`（可选）。
- 复制/粘贴：优先支持系统快捷键，同时提供按钮。

## 9. 兼容性与降级
- 复制/粘贴优先使用 Clipboard API；若不可用则提示手动操作。
- 小屏幕下宽度自适应，不强制 3x；以 95% 视口宽度为上限。

## 10. 非功能性要求
- 文案、按钮、提示均使用中文。
- 不影响现有的本地存储持久化、节点选择、标签高亮及 Emoji 显示。
- 代码结构清晰，便于后续扩展实时预览（Markdown 渲染）能力。

## 11. 里程碑
- 阶段一：UI 与布局（全屏/会话列表/解析与跳转/同步）。
- 阶段二：工具栏按钮与剪贴板、字号、快捷键完善。
- 阶段三（可选）：Markdown 预览与双栏编辑。
