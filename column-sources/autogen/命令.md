# Autogen管理页面启动命令

## 启动方式

### 方法1：Python启动（推荐）
```bash
cd column-sources\autogen
python start_autogen.py
```

### 方法2：直接打开HTML
```bash
# 在浏览器中打开
column-sources\autogen\autogen-manager.html
```

## 访问地址
- **本地地址**: http://localhost:8003/column-sources/autogen/autogen-manager.html

## 功能说明

### 1. Team/Agent管理
- 查看和选择已配置的Team
- 查看Team中的Agent成员
- 创建新的Team和Agent

### 2. 配置管理
- 编辑Agent的系统提示词
- 配置模型参数（model, temperature等）
- 实时保存到数据底座

### 3. 测试实验框
- 输入测试内容
- 运行Agent测试
- 查看测试结果
- 保存成功的提示词模板

### 4. 数据底座集成
- 所有配置自动保存到AutogenUnifiedStorage
- 提示词自动分类和打标签
- 操作历史记录

## 依赖说明

### 前端依赖
- AutogenUnifiedStorage（统一存储）
- AutogenEventBus（事件系统）
- ErrorHandler（错误处理）
- DataCompressor（数据压缩）

### 后端依赖（未来）
