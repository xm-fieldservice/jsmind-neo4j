# 🎯 事件数据修复直接编辑标题持久化指南

## 📋 问题根因分析

**从用户日志发现的关键问题**：
```
[01:58:21] jsMind事件: 3 {"evt":"update_node","data":["sub2","11111"],"node":"sub2"}
[01:58:21] 节点编辑事件，触发自动保存 {"evt":"update_node","data":["sub2","11111"],"node":"sub2"}
[01:58:21] 编辑事件后获取当前节点: null  // 问题在这里！
```

**问题根因**：
1. ❌ **`this.jm.get_selected_node()`返回null**: 在edit事件处理中无法获取当前节点
2. ❌ **事件处理时机错误**: jsMind在编辑过程中可能暂时没有选中节点
3. ❌ **应该从事件数据获取**: 事件数据中已经包含了节点ID和新标题信息

## 🔧 修复方案

### **1. 从事件数据中获取节点信息**
```javascript
// 修复前（错误的方式）
const currentNode = this.jm.get_selected_node();  // 返回null
console.log('[脑图工作栏] 编辑事件后获取当前节点:', currentNode);

// 修复后（正确的方式）
const nodeId = data.node;  // 从事件数据获取节点ID
const newTitle = data.data && data.data.length > 1 ? data.data[1] : null;  // 获取新标题
console.log('[脑图工作栏] 编辑事件数据 - 节点ID:', nodeId, '新标题:', newTitle);
```

### **2. 使用节点ID直接获取节点**
```javascript
if (nodeId && newTitle && nodeId === this.currentNodeId) {
    const currentNode = this.jm.get_node(nodeId);  // 通过ID获取节点
    console.log('[脑图工作栏] 通过ID获取编辑节点:', currentNode);
    
    if (currentNode) {
        const titleInput = document.getElementById('nodeTitleEditor');
        
        if (titleInput && titleInput.value !== currentNode.topic) {
            titleInput.value = currentNode.topic;  // 同步到右侧编辑框
            document.getElementById('currentNode').textContent = currentNode.topic;  // 同步UI
            
            // 调用静默保存
            console.log('[脑图工作栏] edit事件模仿编辑按键，调用静默保存');
            this.saveContentFromSidebarSilent().catch(err => {
                console.error('[脑图工作栏] edit事件模仿编辑按键保存失败:', err);
            });
            return; // 已经保存了，不需要再调用autoSave
        }
    }
}
```

### **3. 在其他事件中也使用相同逻辑**
```javascript
// 检查是否是节点标题编辑事件
if (data && data.evt === 'update_node') {
    const nodeId = data.node;
    const newTitle = data.data && data.data.length > 1 ? data.data[1] : null;
    console.log('[脑图工作栏] 检测到节点更新事件 - 节点ID:', nodeId, '新标题:', newTitle, '当前节点ID:', this.currentNodeId);
    
    if (nodeId && newTitle && nodeId === this.currentNodeId) {
        const currentNode = this.jm.get_node(nodeId);
        if (currentNode) {
            const titleInput = document.getElementById('nodeTitleEditor');
            
            if (titleInput && titleInput.value !== currentNode.topic) {
                titleInput.value = currentNode.topic;
                document.getElementById('currentNode').textContent = currentNode.topic;
                
                // 调用静默保存
                console.log('[脑图工作栏] 模仿编辑按键，调用静默保存');
                this.saveContentFromSidebarSilent().catch(err => {
                    console.error('[脑图工作栏] 模仿编辑按键保存失败:', err);
                });
                return; // 已经保存了，不需要再调用autoSave
            }
        }
    }
}
```

## ✅ 修复优势

### **1. 可靠的数据源**
- 直接从jsMind事件数据获取节点信息
- 避免依赖可能为null的`get_selected_node()`
- 确保获取到正确的节点ID和新标题

### **2. 精确的事件处理**
- 只处理当前选中节点的编辑事件
- 通过节点ID匹配确保处理正确的节点
- 避免处理无关节点的编辑事件

### **3. 完整的数据流**
```
用户双击节点编辑 → jsMind内部更新 → 触发edit/update_node事件 → 从事件数据获取节点信息 → 同步到右侧编辑框 → 调用静默保存 → 完整的数据持久化
```
