## 📖 功能说明

### 基础操作

#### 1. 节点操作
- **选中节点**: 点击任意节点
- **添加节点**: 选中父节点 → 点击"➕ 添加节点"
- **编辑节点**: 选中节点 → 点击"✏️ 编辑"
- **编辑属性**: 选中节点 → 点击"🏷️ 属性" → 编辑元数据
- **删除节点**: 选中节点 → 点击"🗑️ 删除"（根节点不可删除）

#### 2. 搜索功能 ⭐
- **搜索节点**: 在搜索框输入关键词
- **自动定位**: 自动选中第一个匹配的节点
- **实时搜索**: 边输入边搜索

#### 3. 视图操作
- **展开全部**: 点击"📂 展开"
- **折叠全部**: 点击"📁 折叠"
- **放大**: 点击"🔍+"
- **缩小**: 点击"🔍-"
- **重置视图**: 点击"🎯 重置"
- **全屏**: 点击"⛶ 全屏"

#### 4. 数据操作
- **保存**: 点击"💾 保存"（保存到localStorage + 控制台）
- **查看数据**: 按F12打开开发者工具

#### 5. 属性编辑 ⭐
- **itemType**: 节点类型（task/project/phase/subtask/issue）
- **status**: 状态（pending/in_progress/completed/on_hold）
- **priority**: 优先级（low/medium/high/urgent）
- **assignee**: 负责人
- **tags**: 标签（逗号分隔）

## 📊 数据格式示例

### 数据底座规范 v1.2

测试数据遵循 **数据底座规范v1.2（关系表达增强版）**

**核心结构**：
```javascript
{
  id: "node_id",
  topic: "节点标题",
  children: [...],
  
  // data层：纯业务内容数据
  data: {
    content: "节点内容",
    priority: "P0",
    estimatedDays: 10
  },
  
  // meta层：元数据和关系（v1.2规范）
  meta: {
    itemType: "task",          // 项目类型
    parentId: "parent_id",     // 父节点ID
    status: "in_progress",     // 状态
    assignee: "负责人",
    tags: ["标签1", "标签2"],
    
    // v1.1 简化关系（向后兼容）
    relatedIds: ["xxx", "yyy"],
    dependencies: ["zzz"],
    
    // ⭐ v1.2 详细关系数组
    relations: [
      {
        id: "rel_001",
        type: "depends_on",      // 关系类型
        targetId: "node_xxx",
        targetTopic: "目标节点",
        strength: 0.95,          // 关系强度
        confidence: 1.0,         // 置信度
        source: "user_defined",  // 关系来源
        bidirectional: false,
        createdAt: 1696320000000,
        reason: "依赖原因"
      }
    ]
  }
}
```

### 关系类型（v1.2支持）

**用户定义关系**：
- `parent_child` - 父子关系
- `depends_on` - 依赖关系
- `relates_to` - 一般关联
- `blocks` - 阻塞关系
- `duplicates` - 重复关系

**Neo4j推断关系**：
- `semantic_similar` - 语义相似
- `temporal_follows` - 时序后继
- `co_occurrence` - 共现关系
- `causal_link` - 因果关系

### 输入数据格式示例
```json
{
  "meta": {
    "name": "我的脑图",
    "version": "1.0"
  },
  "format": "node_tree",
  "data": {
    "id": "root",
    "topic": "中心主题",
    "data": {
      "content": "节点内容"
    },
    "meta": {
      "itemType": "project",
      "status": "planning"
    },
    "children": [
      {
        "id": "sub1",
        "topic": "子主题1",
        "direction": "right",
        "meta": {
          "itemType": "task",
          "parentId": "root"
        },
        "children": [...]
      }
    ]
  }
}
```
