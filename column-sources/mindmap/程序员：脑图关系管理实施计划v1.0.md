## 📋 实施概述

### 项目目标
基于需求文档v1.0，实现通过复制节点建立逻辑关系的脑图关系管理系统，完全对齐Neo4j图数据库关系模型。

### 实施原则
1. **架构优先**: 充分利用Autogen框架和jsMind内生方法
2. **用户体验**: 优先实现拖拽复制和快捷键功能
3. **模块化**: RelationManager作为独立模块，通过依赖注入集成
4. **数据驱动**: 通过node.data属性存储关系数据，支持持久化

## 🔧 技术实施方案

### 1. 核心组件设计

#### 1.1 RelationManager 模块
```javascript
class RelationManager {
  constructor(jm, options = {}) {
    this.jm = jm; // jsMind实例
    this.storage = window.AutogenUnifiedStorage;
    this.eventBus = window.AutogenEventBus;
    this.errorHandler = window.ErrorHandler;
  }
  
  // 核心API
  createRelationNode(sourceNode, targetParent, relationType, options = {})
  updateSourceNodeCounter(sourceNode)
  copyChildrenRecursively(sourceNode, targetNode, relationData)
  exportToNeo4jCypher()
}
```

### 2. 与现有架构集成

#### 2.1 存储层集成
- 使用 `AutogenUnifiedStorage` 存储关系数据
- 复用现有的分层存储机制（MEMORY → LOCAL_STORAGE → INDEXED_DB）

#### 2.2 事件系统集成
- 使用 `AutogenEventBus` 发布关系事件
- 事件类型：`mindmap.relation.created`, `mindmap.relation.updated`

#### 2.3 错误处理集成
- 使用 `ErrorHandler` 统一错误处理
- 错误分类：RELATION_CREATION_ERROR, RELATION_VALIDATION_ERROR

#### 2.4 现有关系组件集成
- 复用 `RelationDataManager` 的关系数据管理
- 扩展 `MindmapRelationExtractor` 的关系提取功能
