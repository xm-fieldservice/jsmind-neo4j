## 📋 需求分析

### 🎯 功能概述
为脑图节点添加鼠标右键菜单，提供快捷的复制、粘贴、导出等操作，提升用户操作效率。

### 📸 原始需求（来自截图）

**节点鼠标右键菜单** 包含以下功能：

1. **拷贝节点标题到剪贴板**
2. **拷贝节点和内容到剪贴板**
3. **拷贝节点和子节点的标题到剪贴板（带格式）**
4. **拷贝节点和所有子节点的标题和内容以MD格式到剪贴板**
5. **将剪贴板内的内容粘贴到内容框的尾部，中间用"---..."分隔**

## 📊 功能详细设计

### 功能1: 拷贝节点标题到剪贴板

**功能描述**: 复制当前选中节点的标题文本到系统剪贴板

**实现方式**:
```javascript
async copyNodeTitle(node) {
    const title = node.topic;
    await navigator.clipboard.writeText(title);
    console.log('[右键菜单] 已复制标题:', title);
}
```

**输出格式**:
```
节点标题
```

---

### 功能2: 拷贝节点和内容到剪贴板

**功能描述**: 复制节点标题和节点内容（data.content）到剪贴板

**实现方式**:
```javascript
async copyNodeWithContent(node) {
    const title = node.topic;
    const content = node.data?.content || '';
    const text = `${title}\n\n${content}`;
    await navigator.clipboard.writeText(text);
    console.log('[右键菜单] 已复制节点和内容');
}
```

**输出格式**:
```
节点标题

节点内容详细描述...
```

---

### 功能3: 拷贝节点和子节点的标题到剪贴板（带格式）

**功能描述**: 递归复制节点及其所有子节点的标题，使用缩进表示层级关系

**实现方式**:
```javascript
async copyNodeTreeTitles(node) {
    const extractTitles = (node, level = 0) => {
        const indent = '  '.repeat(level);
        let result = `${indent}- ${node.topic}\n`;
        
        if (node.children && node.children.length > 0) {
            node.children.forEach(child => {
                result += extractTitles(child, level + 1);
            });
        }
        
        return result;
    };
    
    const text = extractTitles(node);
    await navigator.clipboard.writeText(text);
    console.log('[右键菜单] 已复制节点树标题');
}
```

**输出格式**:
```
- 父节点标题
  - 子节点1标题
    - 孙节点1标题
    - 孙节点2标题
  - 子节点2标题
```

---

### 功能4: 拷贝节点树的标题和内容以MD格式到剪贴板

**功能描述**: 递归复制节点及其所有子节点的标题和内容，使用Markdown格式

**实现方式**:
```javascript
async copyNodeTreeMarkdown(node) {
    const extractMarkdown = (node, level = 1) => {
        const heading = '#'.repeat(level);
        let result = `${heading} ${node.topic}\n\n`;
        
        // 添加节点内容
        if (node.data?.content) {
            result += `${node.data.content}\n\n`;
        }
        
        // 递归处理子节点
        if (node.children && node.children.length > 0) {
            node.children.forEach(child => {
                result += extractMarkdown(child, level + 1);
            });
        }
        
        return result;
    };
    
    const markdown = extractMarkdown(node);
    await navigator.clipboard.writeText(markdown);
    console.log('[右键菜单] 已复制节点树Markdown');
}
```

**输出格式**:
```markdown
# 父节点标题

父节点内容详细描述...

## 子节点1标题

子节点1内容...

### 孙节点1标题

孙节点1内容...

## 子节点2标题

子节点2内容...
```

### 功能5: 将剪贴板内容粘贴到内容框尾部

**功能描述**: 读取剪贴板内容，追加到当前节点的内容框尾部，使用分隔符分隔

**实现方式**:
```javascript
async pasteToContentEnd(node) {
    try {
        // 读取剪贴板内容
        const clipboardText = await navigator.clipboard.readText();
        
        if (!clipboardText) {
            alert('剪贴板为空');
            return;
        }
        
        // 获取当前内容
        const currentContent = node.data?.content || '';
        
        // 构建新内容（使用分隔符）
        const separator = '\n\n---\n\n';
        const newContent = currentContent 
            ? `${currentContent}${separator}${clipboardText}`
            : clipboardText;
        
        // 更新节点内容
        if (!node.data) node.data = {};
        node.data.content = newContent;
        
        // 更新编辑框显示
        const editor = document.getElementById('nodeContentEditor');
        if (editor) {
            editor.value = newContent;
        }
        
        // 触发保存
        await this.mindmapColumn.autoSave();
        
        console.log('[右键菜单] 已粘贴内容到尾部');
        alert('内容已粘贴到节点内容尾部');
    } catch (err) {
        console.error('[右键菜单] 粘贴失败:', err);
        alert('粘贴失败: ' + err.message);
    }
}
```

**效果示例**:
```
原有内容...

---

粘贴的新内容...
```

### 1. ContextMenuManager类

```javascript
class ContextMenuManager {
    constructor(mindmapColumn) {
        this.mindmapColumn = mindmapColumn;
        this.menu = null;
        this.currentNode = null;
        this.init();
    }
    
    init() {
        // 创建菜单DOM
        this.createMenuDOM();
        
        // 绑定右键事件
        this.bindContextMenuEvent();
        
        // 绑定菜单项点击事件
        this.bindMenuItemEvents();
        
        // 绑定全局点击隐藏菜单
        this.bindGlobalClick();
    }
    
    createMenuDOM() {
        // 创建菜单HTML结构
    }
    
    bindContextMenuEvent() {
        const container = document.getElementById('jsmind_container');
        container.addEventListener('contextmenu', (e) => {
            e.preventDefault();
            
            // 获取点击的节点
            const node = this.getNodeFromEvent(e);
            if (node) {
                this.showMenu(e.clientX, e.clientY, node);
            }
        });
    }
    
    showMenu(x, y, node) {
        this.currentNode = node;
        this.menu.style.left = x + 'px';
        this.menu.style.top = y + 'px';
        this.menu.style.display = 'block';
    }
    
    hideMenu() {
        this.menu.style.display = 'none';
        this.currentNode = null;
    }

    async handleCopyContent() { /* ... */ }
    async handleCopyTreeTitles() { /* ... */ }
    async handleCopyTreeMarkdown() { /* ... */ }
    async handlePasteContent() { /* ... */ }
}
```

## 🎯 技术亮点

### 1. 剪贴板API使用
使用现代浏览器的 `navigator.clipboard` API，支持异步操作，更安全可靠。

### 2. 递归算法
使用递归算法遍历节点树，支持任意深度的子节点提取。

### 3. Markdown格式化
自动生成标准Markdown格式，支持层级标题和内容分离。

### 4. 用户体验优化
- 菜单智能定位，避免超出屏幕
- 操作反馈（成功/失败提示）
- 分隔符自动添加，避免内容混乱
