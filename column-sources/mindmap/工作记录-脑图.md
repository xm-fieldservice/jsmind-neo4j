## 🔧 快捷键持久化修复

### 📋 问题描述
- ✅ **工具栏按钮操作**: 添加、删除节点可以持久化
- ❌ **快捷键操作**: Tab键添加节点、Delete键删除节点无法持久化

### 🛠️ 修复方案

**添加jsMind事件监听器**：
```javascript
this.jm.add_event_listener((type, data) => {
    if (type === jsMind.event_type.select) {
        // 节点选择事件
    } else if (type === jsMind.event_type.edit) {
        // 节点编辑事件 - 触发自动保存
        this.autoSave();
    } else if (type === jsMind.event_type.show) {
        // 脑图显示事件 - 跳过保存
    } else {
        // 其他事件（快捷键操作）- 触发自动保存
        setTimeout(() => {
            this.updateNodeCount();
            this.updateLastModified();
            this.autoSave();
        }, 100);
    }
});
```

### ✅ 修复结果

**现在支持的快捷键持久化**：
- **Tab/Insert**: 添加子节点 → 自动保存
- **Delete**: 删除节点 → 自动保存  
- **F2**: 编辑节点 → 自动保存
- **Enter**: 确认编辑 → 自动保存
