## 📋 需求概述

### 核心理念
通过**复制节点**的方式建立节点间的逻辑关系，对齐Neo4j图数据库的关系模型，实现脑图中的关系可视化和管理。

### 设计原则
1. **架构优先**: 充分利用现有Autogen框架和jsMind内生方法
2. **数据持久化**: 关系数据通过`node.data`属性存储，利用AutogenUnifiedStorage持久化
3. **可视化标识**: 通过Emoji符号和颜色区分不同关系类型
4. **Neo4j对齐**: 关系类型和方向完全对齐Neo4j模型

## 🎯 功能需求

### 1. 关系类型定义（对齐Neo4j）

| 关系类型 | 符号 | Unicode | 强度 | Neo4j对应 | 说明 |
|---------|------|---------|------|-----------|------|
| **关联关系** | ⬌ | `\u2B0C` | 普通 | `RELATED_TO` | 双向关联，说不清的关系 |
| **强关联关系** | ⇔ | `\u21D4` | 强 | `STRONGLY_RELATED` | 双向强关联 |
| **出向关系** | ⮕ | `\u2B95` | 普通 | `INFLUENCES` | 影响力推及 |
| **强出向关系** | ⮕⮕ | `\u2B95\u2B95` | 强 | `STRONGLY_INFLUENCES` | 强影响力 |
| **入向关系** | 🔙 | `\U0001F519` | 普通 | `CAUSED_BY` | 因果逻辑决定 |
| **强入向关系** | 🔙🔙 | `\U0001F519\U0001F519` | 强 | `STRONGLY_CAUSED_BY` | 强因果逻辑 |

### 2. 关系建立方式

#### 2.1 拖拽复制（鼠标右键）
- **触发方式**: 鼠标右键拖拽节点
- **关系类型**: 默认为⬌关联关系
- **实现方法**: 
  - 利用jsMind的拖拽事件
  - 区分左键（移动）和右键（复制）
  - 调用`jm.add_node()`创建复制节点

#### 2.2 快捷键复制（Ctrl+C/V）
- **触发方式**: Ctrl+C复制，Ctrl+V粘贴
- **关系类型**: 默认为⬌关联关系
- **实现方法**:
  - 利用jsMind的shortcut机制
  - 复用现有的`handles.copy`和`handles.paste`
  - 扩展添加关系标识

#### 2.3 右键菜单（关系管理）
- **触发方式**: 右键菜单 → "关系管理"子菜单
- **关系类型**: 6种关系任选
- **菜单结构**:
  ```
  关系管理 ▶
    ├─ 复制节点⬌关系
    ├─ 复制节点⇔关系
    ├─ 复制节点⮕关系
    ├─ 复制节点⮕⮕关系
    ├─ 复制节点🔙关系
    └─ 复制节点🔙🔙关系
  ```
- **实现方法**:
  - 扩展现有的ContextMenuManager
  - 添加二级菜单项
  - 调用统一的关系创建方法

## 🎨 视觉标识规范

### 1. 关系符号位置
- **位置**: 节点标题最前面
- **格式**: `{符号} {原标题}`
- **示例**: `⬌ 项目需求分析`

### 2. 颜色标识
| 关系类型 | 背景色 | 前景色 | 说明 |
|---------|--------|--------|------|
| 关联关系 | `#ffcccc` | `#000000` | 浅红色 |
| 强关联 | `#ff9999` | `#000000` | 深红色 |
| 出向关系 | `#ccffcc` | `#000000` | 浅绿色 |
| 强出向 | `#99ff99` | `#000000` | 深绿色 |
| 入向关系 | `#ccccff` | `#000000` | 浅蓝色 |
| 强入向 | `#9999ff` | `#000000` | 深蓝色 |

### 3. 子节点继承
- 关系节点的所有子节点都继承相同的颜色标识
- 子节点的`data.isRelationNode`和`data.sourceNodeId`保持一致
- 子节点不添加关系符号前缀

## 📦 实现模块设计

### 1. RelationManager（关系管理器）
```javascript
class RelationManager {
    constructor(jm) {
        this.jm = jm;
        this.storage = window.AutogenUnifiedStorage;
        this.eventBus = window.AutogenEventBus;
    }
    
    /**
     * 创建关系节点
     * @param {Object} sourceNode - 源节点
     * @param {Object} targetParent - 目标父节点
     * @param {String} relationType - 关系类型
     * @returns {Object} 创建的关系节点
     */
    createRelationNode(sourceNode, targetParent, relationType) {
        // 1. 生成新节点ID
        const newNodeId = jsMind.util.uuid.newid();
        
        // 2. 构建关系数据
        const relationData = this._buildRelationData(sourceNode, relationType);
        
        // 3. 添加关系符号到标题
        const newTopic = `${relationData.symbol} ${sourceNode.topic}`;
        
        // 4. 使用jsMind API创建节点
        const newNode = this.jm.add_node(
            targetParent,
            newNodeId,
            newTopic,
            relationData.data
        );
        
        // 5. 设置节点颜色
        this.jm.set_node_color(
            newNodeId,
            relationData.bgColor,
            relationData.fgColor
        );
        
        // 6. 递归复制子节点
        if (sourceNode.children && sourceNode.children.length > 0) {
            this._copyChildren(sourceNode, newNode, relationData);
        }
        
        // 7. 更新源节点计数器
        this._updateSourceNodeCounter(sourceNode);
        
        // 8. 触发事件
        this.eventBus.emit('mindmap.relation.created', {
            sourceNodeId: sourceNode.id,
            targetNodeId: newNodeId,
            relationType: relationType
        });
        
        // 9. 保存到存储
        this._saveRelationData();
        
        return newNode;
    }
    
    /**
     * 构建关系数据
     */
    _buildRelationData(sourceNode, relationType) {
        const relationConfig = RELATION_TYPES[relationType];
        
        return {
            symbol: relationConfig.symbol,
            bgColor: relationConfig.bgColor,
            fgColor: relationConfig.fgColor,
            data: {
                ...sourceNode.data,
                isRelationNode: true,
                sourceNodeId: sourceNode.id,
                relationType: relationType,
                relationSymbol: relationConfig.symbol,
                relationStrength: relationConfig.strength,
                relationDirection: relationConfig.direction,
                createdAt: new Date().toISOString(),
                'background-color': relationConfig.bgColor,
                'foreground-color': relationConfig.fgColor
            }
        };
    }
    
    /**
     * 递归复制子节点
     */
    _copyChildren(sourceNode, targetNode, relationData) {
        sourceNode.children.forEach(child => {
            const childId = jsMind.util.uuid.newid();
            const childData = {
                ...child.data,
                isRelationNode: true,
                sourceNodeId: relationData.data.sourceNodeId,
                relationType: relationData.data.relationType,
                'background-color': relationData.bgColor,
                'foreground-color': relationData.fgColor
            };
            
            const newChild = this.jm.add_node(
                targetNode,
                childId,
                child.topic,  // 子节点不添加符号前缀
                childData
            );
            
            // 递归处理子节点的子节点
            if (child.children && child.children.length > 0) {
                this._copyChildren(child, newChild, relationData);
            }
        });
    }
    
    /**
     * 更新源节点计数器
     */
    _updateSourceNodeCounter(sourceNode) {
        if (!sourceNode.data.copy_count) {
            sourceNode.data.copy_count = 0;
            sourceNode.data.original_topic = sourceNode.topic;
        }
        
        sourceNode.data.copy_count++;
        
        const newTopic = `${sourceNode.data.original_topic} [复制×${sourceNode.data.copy_count}]`;
        this.jm.update_node(sourceNode.id, newTopic);
    }
    
    /**
     * 保存关系数据
     */
    async _saveRelationData() {
        try {
            const mindmapData = this.jm.get_data();
            await this.storage.store('mindmap', 'current', mindmapData);
        } catch (err) {
            window.ErrorHandler.handle(err, {
                component: 'RelationManager',
                action: 'saveRelationData'
            });
        }
    }
}
```

        super.bindEvents();

        items.forEach(item => {

                const action = item.getAttribute('data-action');
                
                if (action.startsWith('copy-')) {

            );

        });

### 1. 关系数据提取
```javascript
class RelationDataExtractor {
    /**
     * 从脑图中提取所有关系
     */
    extractRelations(mindmapData) {
        const relations = [];
        
        const traverse = (node) => {
            if (node.data && node.data.isRelationNode) {
                relations.push({
                    id: `rel_${node.id}`,
                    sourceNodeId: node.data.sourceNodeId,
                    targetNodeId: node.id,
                    type: node.data.relationType,
                    symbol: node.data.relationSymbol,
                    strength: node.data.relationStrength,
                    direction: node.data.relationDirection,
                    createdAt: node.data.createdAt,
                    properties: {
                        topic: node.topic,
                        ...node.data
                    }
                });
            }
            
            if (node.children) {
                node.children.forEach(child => traverse(child));
            }
        };
        
        traverse(mindmapData.data);
        return relations;
    }
    
    /**
     * 转换为Neo4j Cypher语句
     */
    toNeo4jCypher(relations) {
        const statements = relations.map(rel => {
            return `
                MATCH (source {id: '${rel.sourceNodeId}'})
                MATCH (target {id: '${rel.targetNodeId}'})
                CREATE (source)-[:${rel.type} {
                    strength: '${rel.strength}',
                    direction: '${rel.direction}',
                    createdAt: '${rel.createdAt}'
                }]->(target)
            `;
        });
        
        return statements.join('\n');
    }
}
```
