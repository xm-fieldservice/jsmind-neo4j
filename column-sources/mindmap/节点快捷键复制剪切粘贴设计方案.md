---

## 📋 功能需求

### 快捷键定义

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| **Ctrl+C** | 复制节点 | 复制选中节点到剪贴板（包括子节点） |
| **Ctrl+X** | 剪切节点 | 剪切选中节点到剪贴板（删除原节点） |
| **Ctrl+V** | 粘贴节点 | 粘贴剪贴板中的节点到选中节点下 |

### 功能特性

1. **复制（Ctrl+C）**
   - 复制选中节点及其所有子节点
   - 保留节点结构、内容、属性
   - 不删除原节点

2. **剪切（Ctrl+X）**
   - 剪切选中节点及其所有子节点
   - 保留节点结构、内容、属性
   - 删除原节点（根节点不可剪切）

3. **粘贴（Ctrl+V）**
   - 将剪贴板中的节点粘贴为选中节点的子节点
   - 自动生成新的节点ID
   - 保持原有的层级结构

## 🏗️ 技术设计

### 1. 剪贴板管理器

```javascript
class NodeClipboard {
    constructor() {
        this.clipboardData = null;  // 存储复制/剪切的节点数据
        this.operation = null;      // 'copy' 或 'cut'
    }
    
    // 复制节点
    copy(node) {
        this.clipboardData = this.cloneNode(node);
        this.operation = 'copy';
    }
    
    // 剪切节点
    cut(node) {
        this.clipboardData = this.cloneNode(node);
        this.operation = 'cut';
    }
    
    // 粘贴节点
    paste() {
        if (!this.clipboardData) return null;
        
        // 复制操作：保留剪贴板数据
        // 剪切操作：清空剪贴板数据（只能粘贴一次）
        const data = this.cloneNode(this.clipboardData);
        
        if (this.operation === 'cut') {
            this.clear();
        }
        
        return data;
    }
    
    // 克隆节点（深拷贝）
    cloneNode(node) {
        return JSON.parse(JSON.stringify(node));
    }
    
    // 清空剪贴板
    clear() {
        this.clipboardData = null;
        this.operation = null;
    }
    
    // 检查剪贴板是否有数据
    hasData() {
        return this.clipboardData !== null;
    }
}
```

### 2. 节点操作API扩展

在 `MindmapOperations` 类中添加：

```javascript
// 复制节点
copyNode(node) {
    const target = node || this.jm.get_selected_node();
    if (!target) return false;
    
    this.clipboard.copy(target);
    console.log('[节点操作] 已复制节点:', target.topic);
    return true;
}

// 剪切节点
cutNode(node) {
    const target = node || this.jm.get_selected_node();
    if (!target || target.isroot) {
        console.warn('[节点操作] 不能剪切根节点');
        return false;
    }
    
    this.clipboard.cut(target);
    console.log('[节点操作] 已剪切节点:', target.topic);
    return true;
}

// 粘贴节点
pasteNode(parentNode) {
    const parent = parentNode || this.jm.get_selected_node();
    if (!parent) return false;
    
    const nodeData = this.clipboard.paste();
    if (!nodeData) {
        console.warn('[节点操作] 剪贴板为空');
        return false;
    }
    
    // 递归添加节点
    const newNode = this.addNodeTree(parent, nodeData);
    
    // 如果是剪切操作，删除原节点
    if (this.clipboard.operation === 'cut') {
        this.removeNode(nodeData.id);
    }
    
    console.log('[节点操作] 已粘贴节点:', nodeData.topic);
    return newNode;
}

// 递归添加节点树
addNodeTree(parent, nodeData) {
    const newId = 'node_' + Date.now() + '_' + Math.random().toString(36).substr(2, 9);
    
    const node = this.jm.add_node(parent, newId, nodeData.topic, {
        direction: 'right'
    });
    
    if (node) {
        // 复制节点数据
        if (nodeData.data) {
            node.data = JSON.parse(JSON.stringify(nodeData.data));
        }
        
        // 递归添加子节点
        if (nodeData.children && nodeData.children.length > 0) {
            nodeData.children.forEach(child => {
                this.addNodeTree(node, child);
            });
        }
    }
    
    return node;
}
```

const options = {

            'delnode': (jm, e) => this.ops.removeNode(),

                e.preventDefault();
                this.ops.copyNode();
                return false;
            },
            'cut': (jm, e) => {
                e.preventDefault();
                this.ops.cutNode();
                return false;
            },
            'paste': (jm, e) => {
                e.preventDefault();
                this.ops.pasteNode();
                return false;
            }
        },
        mapping: {
            // 默认映射
            addchild: 9,    // Tab
            addbrother: 13, // Enter
            delnode: 46,    // Delete
            
            // 新增映射
            copy: 67,       // C (需要配合Ctrl)
            cut: 88,        // X (需要配合Ctrl)
            paste: 86       // V (需要配合Ctrl)
        }
    }
};

## 🎯 功能流程

### 复制流程

```
1. 用户选择节点
2. 按 Ctrl+C
3. 节点数据（包括子节点）存入剪贴板
4. 显示提示："节点已复制"
```

### 剪切流程

```
1. 用户选择节点（非根节点）
2. 按 Ctrl+X
3. 节点数据存入剪贴板
4. 标记为剪切操作
5. 显示提示："节点已剪切"
```

### 粘贴流程

```
1. 用户选择目标父节点
2. 按 Ctrl+V
3. 从剪贴板读取节点数据
4. 递归创建节点树
5. 如果是剪切操作：
   - 删除原节点
   - 清空剪贴板
6. 如果是复制操作：
   - 保留剪贴板数据（可多次粘贴）
7. 显示提示："节点已粘贴"
```

## 🔧 技术细节

### 1. 节点ID生成

**问题**: 粘贴时需要生成新的节点ID，避免ID冲突

**解决方案**:
```javascript
const newId = 'node_' + Date.now() + '_' + Math.random().toString(36).substr(2, 9);
```

### 2. 深拷贝

**问题**: 确保复制的节点数据完全独立

**解决方案**:
```javascript
cloneNode(node) {
    return JSON.parse(JSON.stringify(node));
}
```

### 3. 递归粘贴

**问题**: 保持原有的节点树结构

**解决方案**:
```javascript
addNodeTree(parent, nodeData) {
    const node = this.jm.add_node(parent, newId, nodeData.topic, {...});
    
    if (nodeData.children) {
        nodeData.children.forEach(child => {
            this.addNodeTree(node, child);  // 递归
        });
    }
}
```

### 4. 剪切操作的特殊处理

**问题**: 剪切后只能粘贴一次

**解决方案**:
```javascript
paste() {
    const data = this.cloneNode(this.clipboardData);
    
    if (this.operation === 'cut') {
        this.clear();  // 剪切操作后清空剪贴板
    }
    
    return data;
}
```
