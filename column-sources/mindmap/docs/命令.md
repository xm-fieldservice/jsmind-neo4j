## AI报告生成规则 v1.0

### 核心原则：三层结构
1. **核心结论** (3-5行) - 直接回答用户问题
2. **关键信息** (结构化) - 必要的技术细节
3. **补充说明** (可选) - 验证方法、注意事项

### 避免的问题
- ❌ 过度详细化：把架构文档全部搬运
- ❌ 信息重复：同一事实从多个角度重复说明
- ❌ 偏离焦点：回答用户没问的问题

### 均衡标准
- ✅ **简洁优先**：能用表格不用段落，能用列表不用表格
- ✅ **分层展示**：核心信息前置，细节可折叠/引用
- ✅ **避免重复**：每个事实只说一次，在最合适的位置
- ✅ **聚焦问题**：围绕用户问题组织内容

### 报告长度参考
| 问题类型 | 建议长度 | 结构 |
|---------|---------|------|
| 简单查询 | 10-20行 | 结论 + 验证方法 |
| 技术检查 | 30-50行 | 结论 + 关键信息 + 补充 |
| 架构审查 | 50-100行 | 概览 + 分析 + 建议 |
| 完整报告 | 100-200行 | 完整结构 + 详细分析 |

### 示例对比

**❌ 过度详细（重复）**
```
1. 四级存储架构
   - MEMORY: 内存缓存...
   - LOCAL_STORAGE: 本地存储...
2. 冷热数据分层
   - HOT: 保留在内存...
   - WARM: 保留在LocalStorage...
3. 数据安全
   - 内存缓存 - 快速访问
   - LocalStorage - 本地持久化
```

**✅ 均衡表达（清晰）**
```
存储架构：四级分层（内存 → LocalStorage → IndexedDB → JSON底座）
- 热数据(≥10次访问) → 内存，<1ms
- 温数据(≥3次访问) → LocalStorage，~10ms
- 冷数据(<3次访问) → IndexedDB，~50ms
- 归档数据 → JSON底座
```
