## 🚨 严重问题清单

### P0 - 严重违规（必须立即修复）

#### 1. **直接访问window.AutogenUnifiedStorage** 🔴
**位置**: 
- `relation-manager.js:26`
- `mindmap-standalone.html:2092`

**问题描述**:
```javascript
// ❌ 违规代码
this.storage = window.AutogenUnifiedStorage;
```

**违反原则**:
- 违反ADR-001：强制使用StorageAdapter
- 绕过依赖注入机制
- 直接耦合到底层存储实现
- 无法进行单元测试（无法mock）

**架构一致性影响**: -25%

**整改要求**:
```javascript
// ✅ 正确做法
constructor(dependencies = {}) {
    this.storageAdapter = dependencies.storageAdapter;
    if (!this.storageAdapter) {
        throw new Error('StorageAdapter是必需的依赖');
    }
}
```

---

#### 2. **MindmapStorage使用@deprecated方法** 🔴
**位置**: `src/data/MindmapStorage.js:189-278`

**问题描述**:
```javascript
// ❌ 存在废弃方法
async saveWithUnifiedStorage(jmData, immediate = false) {
    // 🔧 临时方案：通过StorageAdapter访问底层存储
    const storage = this.storageAdapter.storage;
}
```

**违反原则**:
- 方法标记为@deprecated但仍在使用
- 绕过StorageAdapter直接访问底层storage
- 违反封装原则

**代码冗余**: 约90行重复代码

**整改要求**:
- 删除`saveWithUnifiedStorage()`和`loadFromUnifiedStorage()`
- 统一使用`saveMindmapData()`和`loadMindmapData()`
- 移除所有直接访问`.storage`的代码

---

#### 3. **MindmapCompatLayer未使用StorageAdapter** 🔴
**位置**: `column-sources/mindmap/MindmapCompatLayer.js:186-217`

**问题描述**:
```javascript
// ❌ 违规代码
if (typeof AutogenUnifiedStorage !== 'undefined') {
    const jmData = {...};
    return await AutogenUnifiedStorage.store('mindmap', mindmapId, jmData);
}
```

**违反原则**:
- 兼容层直接使用AutogenUnifiedStorage
- 未通过依赖注入获取StorageAdapter
- 架构不一致

**整改要求**:
- 在`initialize()`时注入StorageAdapter
- 所有存储操作通过StorageAdapter

### P1 - 重要问题（2周内修复）

#### 4. **直接使用localStorage** ⚠️
**位置**: 
- `mindmap-standalone.html:2119`
- `archive/tests/clear-storage.html:19-25`

**问题描述**:
```javascript
// ❌ 违规代码
const lsData = localStorage.getItem(lsKey);
```

**违反原则**:
- 绕过统一存储系统
- 无法享受分层存储、TTL、统计等功能
- 代码分散，难以维护

**整改要求**:
- 所有localStorage操作改为StorageAdapter调用
- 测试脚本可以例外，但需添加注释说明

---

#### 5. **缺少冷热数据分层机制** ⚠️
**位置**: 整个存储系统

**问题描述**:
- AutogenUnifiedStorage已实现三层存储（MEMORY → LOCAL_STORAGE → INDEXED_DB）
- 但缺少基于访问频率的自动冷热数据迁移
- 缺少冷数据归档机制

**参考记忆**: 用户明确需要冷热数据分层存储方案

**整改建议**:
1. 添加访问频率统计
2. 实现自动冷热数据迁移策略
3. 支持冷数据导出到JSON底座
4. 热数据优先保留在内存和LocalStorage

---

#### 6. **JSON底座同步功能未充分利用** ⚠️
**位置**: `src/data/MindmapStorage.js:283-344`

**问题描述**:
- JSON底座同步功能已实现
- 但仅在`MindmapStorage`中使用
- `RelationManager`等组件未使用
- 缺少统一的同步策略

**整改建议**:
- 将JSON底座同步功能提升到StorageAdapter层
- 所有数据类型统一同步策略
- 支持批量同步和增量同步

## 📝 风险评估

### 高风险
- **数据迁移风险**: 修改存储逻辑可能导致数据丢失
  - **缓解措施**: 先备份所有数据，提供数据迁移工具

### 中风险
- **兼容性风险**: 旧代码可能依赖直接访问localStorage
  - **缓解措施**: 渐进式迁移，保留兼容层

### 低风险
- **性能风险**: 增加抽象层可能影响性能
  - **缓解措施**: 性能基准测试，优化关键路径
