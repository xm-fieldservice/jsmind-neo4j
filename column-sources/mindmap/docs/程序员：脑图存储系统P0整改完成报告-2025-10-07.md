## ✅ P0问题修复清单

### 1. RelationManager重构 ✅

**文件**: `column-sources/mindmap/relation-manager.js`

**修改内容**:

#### 1.1 构造函数重构
```javascript
// ❌ 修改前
constructor(jm, options = {}) {
    this.storage = window.AutogenUnifiedStorage;  // 直接访问全局对象
}

// ✅ 修改后
constructor(jm, dependencies = {}, options = {}) {
    this.storageAdapter = dependencies.storageAdapter;
    if (!this.storageAdapter) {
        throw new Error('[RelationManager] StorageAdapter是必需的依赖');
    }
}
```

**改进点**:
- ✅ 强制依赖注入StorageAdapter
- ✅ 移除直接访问window.AutogenUnifiedStorage
- ✅ 提高可测试性（可mock StorageAdapter）
- ✅ 符合ADR-001架构决策

---

#### 1.2 存储方法重构
```javascript
// ❌ 修改前
async _saveToStorage() {
    await this.storage.store('mindmap', 'current', mindmapData);
}

// ✅ 修改后
async _saveToStorage() {
    await this.storageAdapter.saveMindmap(mindmapData);
}
```

**改进点**:
- ✅ 使用StorageAdapter业务方法
- ✅ 隐藏底层存储实现细节
- ✅ 统一存储接口

---

#### 1.3 依赖验证更新
```javascript
// ✅ 修改后
_validateDependencies() {
    if (!this.storageAdapter) {
        console.warn('[RelationManager] StorageAdapter未找到');
    }
}
```

**代码变化**:

### 2. MindmapCompatLayer重构 ✅

**文件**: `column-sources/mindmap/MindmapCompatLayer.js`

**修改内容**:

#### 2.1 添加StorageAdapter支持
```javascript
// ✅ 新增属性
constructor(options = {}) {
    // 🔧 架构整改：添加StorageAdapter引用
    this.storageAdapter = null;
}
```

---

#### 2.2 初始化方法增强
```javascript
// ❌ 修改前
async initialize(jmInstance, standaloneOps) {
    // 无StorageAdapter支持
}

// ✅ 修改后
async initialize(jmInstance, standaloneOps, dependencies = {}) {
    this.storageAdapter = dependencies.storageAdapter;
    if (!this.storageAdapter && typeof window.StorageAdapter !== 'undefined') {
        this.storageAdapter = new window.StorageAdapter();
        await this.storageAdapter.initialize();
    }
}
```

**改进点**:
- ✅ 支持依赖注入StorageAdapter
- ✅ 自动创建StorageAdapter实例（回退方案）
- ✅ 确保StorageAdapter可用

---

#### 2.3 数据保存方法重构
```javascript
// ❌ 修改前
async saveData(mindmapId, data, immediate = false) {
    if (typeof AutogenUnifiedStorage !== 'undefined') {
        return await AutogenUnifiedStorage.store('mindmap', mindmapId, jmData);
    }
}

// ✅ 修改后
async saveData(mindmapId, data, immediate = false) {
    if (this.storageAdapter) {
        const jmData = {
            meta: { name: 'Mindmap', author: 'local', version: '1.0' },
            format: 'node_tree',
            data: this._convertToJsMindFormat(data),
            id: mindmapId || 'current'
        };
        return await this.storageAdapter.saveMindmap(jmData);
    }
    this._warn('StorageAdapter不可用，无法保存数据');
    return false;
}
```

**改进点**:
- ✅ 移除直接访问AutogenUnifiedStorage
- ✅ 使用StorageAdapter统一接口
- ✅ 添加错误提示

---

#### 2.4 数据加载方法重构
```javascript
// ❌ 修改前
async loadData(mindmapId) {
    if (typeof AutogenUnifiedStorage !== 'undefined') {
        const stored = await AutogenUnifiedStorage.retrieve('mindmap', mindmapId);
        return stored;
    }
}

// ✅ 修改后
async loadData(mindmapId) {
    if (this.storageAdapter) {
        const stored = await this.storageAdapter.loadMindmap(mindmapId || 'current');
        if (stored && stored.data) {
            return this._convertFromJsMindFormat(stored.data);
        }
    }
    this._warn('StorageAdapter不可用或数据不存在');
    return null;
}
```

**代码变化**:
- 删除: 30行
- 新增: 40行
- 净增加: +10行
