# 🎯 脑图数据底座保存功能使用指南

## 📋 功能概述

基于数据底座规范v1.2，实现了脑图数据按照标准格式保存到文件系统的功能。点击"💾 保存"按钮时，系统会：

1. **内存保存**: 保存到AutogenUnifiedStorage统一存储系统
2. **文件保存**: 使用filepicker按照数据底座规范v1.2格式保存到用户选择的目录

## 🔧 技术实现

### **核心功能**
- `saveMindmapToDataBase()`: 主保存方法
- `convertToDataBaseFormat()`: 数据格式转换
- `saveWithFilePicker()`: 文件选择和保存

### **数据转换规范**
按照数据底座规范v1.2，数据结构包含：

```javascript
{

  "format": "node_tree",
  "data": {
    "id": "root",
    "topic": "中心主题",
    "children": [...],
    
    // data层：纯业务内容数据
    "data": {
      "content": "节点内容",
      // 其他业务字段

    // meta层：统一的关系表达（v1.2规范）

      // v1.1兼容字段
      "relatedIds": ["xxx", "yyy"],
```

## 🚀 使用方法

### **步骤1: 编辑脑图**
1. 在脑图中创建和编辑节点
2. 添加节点内容和标题
3. 设置节点属性（状态、优先级等）

### **步骤2: 点击保存按钮**
1. 点击工具栏中的"💾 保存"按钮
2. 系统会自动保存到内存存储
3. 弹出文件保存对话框

### **步骤3: 选择保存位置**
1. **现代浏览器**: 使用File System Access API，选择保存位置和文件名
2. **传统浏览器**: 自动下载到默认下载目录

### **步骤4: 确认保存**
- 保存成功会显示"脑图已保存到数据底座！"
- 保存失败会显示具体错误信息

## 📁 文件格式

### **文件名格式**
- 默认: `mindmap_YYYY-MM-DD.json`
- 例如: `mindmap_2025-10-04.json`

### **文件内容**
- 格式: JSON
- 编码: UTF-8
- 结构: 符合数据底座规范v1.2

## 🛠️ 浏览器兼容性

### **支持File System Access API的浏览器**
- Chrome 86+
- Edge 86+
- 功能: 用户可选择保存位置和文件名

### **不支持的浏览器**
- Firefox
- Safari
- 功能: 自动下载到默认目录

## ⚠️ 注意事项

### **数据完整性**
- 所有节点内容和标题都会被保存
- 节点属性（状态、优先级、负责人、标签）会被保存
- 关系数据会转换为v1.2规范格式

### **文件安全**
- 用户完全控制保存位置
- 不会自动上传到任何服务器
- 数据保存在用户本地

### **错误处理**
- 保存失败会显示具体错误信息
- 用户取消保存不会影响内存数据
- 网络问题不会影响本地保存

## 🎯 最佳实践

### **定期保存**
- 建议在重要修改后及时保存
- 可以保存多个版本作为备份

### **文件命名**
- 使用有意义的文件名
- 包含日期和版本信息
- 例如: `项目规划_v1.2_2025-10-04.json`

### **版本管理**
- 保存的文件可以用作版本控制
- 可以与团队共享标准格式的脑图数据
- 支持后续导入和分析

## 🔍 故障排除

### **保存失败**
1. 检查浏览器是否支持文件保存
2. 确认有足够的磁盘空间
3. 检查文件权限

### **数据丢失**
1. 检查AutogenUnifiedStorage中的备份
2. 查看浏览器控制台的错误信息
3. 尝试重新保存

### **格式问题**
1. 确认保存的是JSON格式
2. 检查文件编码是否为UTF-8
3. 验证数据结构是否符合v1.2规范

## 🚀 立即使用

1. 打开脑图应用
2. 创建或编辑脑图内容
3. 点击"💾 保存"按钮
4. 选择保存位置
5. 确认保存完成

现在你的脑图数据将按照数据底座规范v1.2格式保存，便于后续的数据分析和系统集成！
