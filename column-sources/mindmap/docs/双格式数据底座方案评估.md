# 双格式数据底座方案评估

**方案**: 手动保存时同时保存JSON和MD两种格式  
**评估时间**: 2025-10-07  
**评估人**: 程序员

## 📋 方案概述

### 核心思路
- **运行时**: 使用JSON格式（快速加载和操作）
- **手动保存**: 同时保存JSON和MD两种格式
- **MD格式**: 作为备份 + 人类可读版本
- **自动保存**: 仅保存JSON格式（性能优先）

#### 1.1 实现MD转换器
```javascript
// src/data/MDConverter.js
class MDConverter {
    /**
     * JSON转MD格式
     * @param {Object} data - 脑图JSON数据
     * @returns {String} MD格式字符串
     */
    jsonToMD(data) {
        const lines = [];
        
        // 1. 元数据
        lines.push(`# ${data.meta.name || 'Untitled'}`);
        lines.push(`@author: ${data.meta.author || ''}`);
        lines.push(`@version: ${data.meta.version || '1.0'}`);
        lines.push(`@created: ${this._formatDate(data.meta.createdAt)}`);
        lines.push(`@updated: ${this._formatDate(data.meta.updatedAt)}`);
        lines.push('');
        
        // 2. 递归处理节点树
        this._nodeToMD(data.data, lines, 2);
        
        return lines.join('\n');
    }
    
    /**
     * 节点转MD
     */
    _nodeToMD(node, lines, level) {
        // 标题
        const heading = '#'.repeat(level);
        lines.push(`${heading} ${node.topic}`);
        
        // 元数据
        lines.push(`@id: ${node.id}`);
        if (node.meta?.createdAt) {
            lines.push(`@created: ${this._formatDate(node.meta.createdAt)}`);
        }
        if (node.meta?.updatedAt) {
            lines.push(`@updated: ${this._formatDate(node.meta.updatedAt)}`);
        }
        
        // 内容
        if (node.data?.content) {
            lines.push('');
            lines.push(node.data.content);
        }
        
        lines.push('');
        
        // 递归处理子节点
        if (node.children && node.children.length > 0) {
            for (const child of node.children) {
                this._nodeToMD(child, lines, level + 1);
            }
        }
    }
    
    /**
     * MD转JSON格式
     * @param {String} mdString - MD格式字符串
     * @returns {Object} 脑图JSON数据
     */
    mdToJSON(mdString) {
        const lines = mdString.split('\n');
        
        // 1. 解析元数据
        const meta = this._parseMeta(lines);
        
        // 2. 解析节点树
        const data = this._parseNodes(lines);
        
        return {
            meta,
            format: 'node_tree',
            data
        };
    }
    
    _formatDate(timestamp) {
        return new Date(timestamp).toISOString().replace('T', ' ').substring(0, 19);
    }
}
```

#### 1.2 修改保存逻辑
```javascript
// src/data/MindmapStorage.js
class MindmapStorage {
    constructor() {
        this.converter = new MDConverter();
    }
    
    /**
     * 自动保存（仅JSON）
     */
    async autoSave(data) {
        const compressed = this.compressor.compress(data);
        await this.storage.store('mindmap', 'current.json', compressed);
        console.log('[AutoSave] ✅ JSON格式已保存');
    }
    
    /**
     * 手动保存（JSON + MD）
     */
    async manualSave(data) {
        // 1. 保存JSON格式
        const compressed = this.compressor.compress(data);
        await this.storage.store('mindmap', 'current.json', compressed);
        
        // 2. 保存MD格式
        const mdString = this.converter.jsonToMD(data);
        await this.storage.store('mindmap', 'current.md', mdString);
        
        // 3. 添加时间戳版本（可选）
        const timestamp = Date.now();
        await this.storage.store('mindmap', `backup_${timestamp}.md`, mdString);
        
        console.log('[ManualSave] ✅ JSON和MD格式已保存');
        
        // 4. 清理旧版本
        await this.cleanOldBackups();
    }
    
    /**
     * 加载（始终从JSON）
     */
    async load() {
        try {
            // 1. 尝试从JSON加载
            const data = await this.storage.retrieve('mindmap', 'current.json');
            if (data) {
                return this.compressor.decompress(data);
            }
        } catch (error) {
            console.warn('[Load] JSON加载失败，尝试从MD恢复', error);
        }
        
        try {
            // 2. JSON失败，从MD恢复
            const mdString = await this.storage.retrieve('mindmap', 'current.md');
            if (mdString) {
                console.warn('[Load] 从MD格式恢复数据');
                return this.converter.mdToJSON(mdString);
            }
        } catch (error) {
            console.error('[Load] MD加载也失败', error);
        }
        
        // 3. 都失败，返回默认数据
        return this.getDefaultData();
    }
    
    /**
     * 清理旧备份
     */
    async cleanOldBackups() {
        const keys = await this.storage.list('mindmap');
        const backups = keys.filter(k => k.startsWith('backup_'));
        
        if (backups.length > 5) {
            // 按时间排序
            backups.sort();
            
            // 删除最旧的
            const toDelete = backups.slice(0, backups.length - 5);
            for (const key of toDelete) {
                await this.storage.remove('mindmap', key);
            }
            
            console.log(`[Cleanup] 清理了${toDelete.length}个旧备份`);
        }
    }
}
```

#### 2.1 版本管理
```javascript
class VersionManager {
    async saveVersion(data, comment) {
        const timestamp = Date.now();
        const version = {
            timestamp,
            comment,
            json: data,
            md: this.converter.jsonToMD(data)
        };
        
        await this.storage.store('versions', `v_${timestamp}`, version);
    }
    
    async listVersions() {
        const keys = await this.storage.list('versions');
        return keys.map(k => ({
            id: k,
            timestamp: parseInt(k.split('_')[1]),
            date: new Date(parseInt(k.split('_')[1])).toLocaleString()
        }));
    }
    
    async restoreVersion(versionId) {
        const version = await this.storage.retrieve('versions', versionId);
        return version.json;
    }
}
```
