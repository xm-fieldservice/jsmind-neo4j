# 快捷键映射问题修复

**问题发现**: 2025-10-04 17:48  
**修复人员**: 程序员  

---

## 🔴 问题描述

Tab键（添加子节点）快捷键失效，但Enter键（添加兄弟节点）正常工作。

---

## 🔍 根本原因

在实施快捷键复制/剪切/粘贴功能时，我错误地添加了 `mapping` 配置：

```javascript
shortcut: {
    enable: true,
    handles: { ... },
    mapping: {
        addchild: 9,    // Tab
        addbrother: 13, // Enter
        delnode: 46     // Delete
    }
}
```

**问题**: 这个 `mapping` 配置**覆盖了jsMind的默认快捷键映射**，导致Tab键失效。

---

## ✅ 修复方案

**删除 `mapping` 配置，使用jsMind默认快捷键**

```javascript
shortcut: {
    enable: true,
    handles: {
        'addchild': (jm, e) => {
            console.log('[脑图工作栏] 快捷键: 添加子节点');
            return this.ops.addChild();
        },
        'addbrother': (jm, e) => {
            console.log('[脑图工作栏] 快捷键: 添加兄弟节点');
            return this.ops.addBrother();
        },
        'delnode': (jm, e) => {
            console.log('[脑图工作栏] 快捷键: 删除节点');
            return this.ops.removeNode();
        }
    }
    // ✅ 不设置mapping，使用jsMind默认快捷键
}
```

---

## 📊 jsMind默认快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| **Tab** | 添加子节点 | addchild |
| **Enter** | 添加兄弟节点 | addbrother |
| **Delete** | 删除节点 | delnode |
| **F2** | 编辑节点 | editnode |

## 📝 经验教训

1. **不要随意覆盖默认配置** - jsMind的默认快捷键已经很好用
2. **只覆盖handles** - 只需要覆盖处理函数，不需要修改键位映射
3. **测试所有快捷键** - 修改后要测试所有相关功能
