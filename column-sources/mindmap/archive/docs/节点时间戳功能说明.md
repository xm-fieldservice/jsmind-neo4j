## 📋 功能概述

为所有新建节点自动添加创建时间戳到内容框，时间戳格式为 `YYYY-MM-DD HH:MM:SS`，并在时间戳下方自动添加一行空行，方便用户继续输入内容。

---

### 1. 修改的方法

**文件**: `mindmap-operations.js`

| 方法 | 触发方式 | 修改内容 |

| `addBrother()` | Enter键 | 添加时间戳到 `data.content` |

**示例**: `2025-10-04 17:25:41`

## 🔧 技术实现

### getTimestamp() 方法

```javascript
// 获取格式化时间戳
getTimestamp() {
    const now = new Date();
    const year = now.getFullYear();
    const month = String(now.getMonth() + 1).padStart(2, '0');
    const day = String(now.getDate()).padStart(2, '0');
    const hours = String(now.getHours()).padStart(2, '0');
    const minutes = String(now.getMinutes()).padStart(2, '0');
    const seconds = String(now.getSeconds()).padStart(2, '0');
    
    return `${year}-${month}-${day} ${hours}:${minutes}:${seconds}`;
}
```

## 📝 使用说明

### 用户操作

**方式1: 使用Tab键**
1. 选择一个节点
2. 按 Tab 键
3. 输入节点标题
4. 节点内容框自动显示时间戳和空行

**方式2: 使用Enter键**
1. 选择一个节点（非根节点）
2. 按 Enter 键
3. 输入节点标题
4. 节点内容框自动显示时间戳和空行

**方式3: 使用按钮**
1. 选择一个节点
2. 点击"➕ 添加节点"按钮
3. 在弹窗中输入节点标题
4. 节点内容框自动显示时间戳和空行

### 查看时间戳

**方式1: 右侧编辑框**
- 选择节点后，右侧编辑框会显示节点内容
- 时间戳显示在内容框顶部

**方式2: 右键菜单**
- 右键点击节点
- 选择"拷贝节点和内容到剪贴板"
- 粘贴到其他应用查看
