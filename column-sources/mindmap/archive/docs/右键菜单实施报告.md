## ✅ 已实现功能

### 功能1: 拷贝节点标题到剪贴板 ✅
- **实现方法**: `handleCopyTitle()`
- **功能**: 复制当前节点的标题文本
- **输出格式**: 纯文本标题

### 功能2: 拷贝节点和内容到剪贴板 ✅
- **实现方法**: `handleCopyContent()`
- **功能**: 复制节点标题 + 节点内容（data.content）
- **输出格式**:
  ```
  节点标题
  
  节点内容...
  ```

### 功能3: 拷贝节点树标题（带格式） ✅
- **实现方法**: `handleCopyTreeTitles()` + `collectNodeTreeTitles()`
- **功能**: 递归复制节点及所有子节点的标题，使用缩进表示层级
- **输出格式**:
  ```
  - 父节点
    - 子节点1
      - 孙节点1
    - 子节点2
  ```

### 功能4: 拷贝节点树MD格式 ✅
- **实现方法**: `handleCopyTreeMarkdown()` + `collectNodeTreeMarkdown()`
- **功能**: 递归复制节点树，使用Markdown格式
- **输出格式**:
  ```markdown
  # 父节点
  
  父节点内容...
  
  ## 子节点1
  
  子节点1内容...
  ```

### 功能5: 粘贴到内容框尾部 ✅
- **实现方法**: `handlePasteContent()`
- **功能**: 读取剪贴板内容，追加到节点内容框尾部
- **分隔符**: `\n\n---\n\n`
- **自动保存**: 粘贴后自动触发保存

### 2. 关键技术点

#### 右键事件绑定（采纳用户建议）
```javascript
// 使用jsMind的view.e_panel绑定右键事件
const panel = this.jm.view.e_panel;

panel.addEventListener('contextmenu', (e) => {
    e.preventDefault();
    
    // 使用jsMind API获取节点ID
    const nodeId = this.jm.view.get_binded_nodeid(e.target);
    
    // 检查是否点击在节点上
    if (nodeId && this.jm.view.is_node(e.target)) {
        const node = this.jm.get_node(nodeId);
        if (node) {
            this.showMenu(e.clientX, e.clientY, node);
        }
    }
});
```

#### 递归算法（限制深度）
```javascript
collectNodeTreeTitles(node, depth, currentDepth) {
    // 限制递归深度，避免性能问题
    if (currentDepth >= this.maxRecursionDepth) {
        console.warn('[右键菜单] 达到最大递归深度，停止遍历');
        return '';
    }
    
    const indent = '  '.repeat(depth);
    let result = `${indent}- ${node.topic}\n`;
    
    // 递归处理子节点
    if (node.children && node.children.length > 0) {
        node.children.forEach(child => {
            result += this.collectNodeTreeTitles(child, depth + 1, currentDepth + 1);
        });
    }
    
    return result;
}
```

#### 智能菜单定位（避免超出屏幕）
```javascript
showMenu(x, y, node) {
    // 智能定位，避免超出屏幕
    const menuRect = this.menu.getBoundingClientRect();
    const menuWidth = menuRect.width || 280;
    const menuHeight = menuRect.height || 200;
    
    const maxX = window.innerWidth - menuWidth;
    const maxY = window.innerHeight - menuHeight;
    
    const finalX = Math.min(x, maxX);
    const finalY = Math.min(y, maxY);
    
    this.menu.style.left = finalX + 'px';
    this.menu.style.top = finalY + 'px';
    this.menu.style.display = 'block';
}
```

#### 剪贴板API（含降级方案）
```javascript
async copyToClipboard(text) {
    try {
        // 使用现代剪贴板API
        await navigator.clipboard.writeText(text);
    } catch (err) {
        // 降级方案：使用document.execCommand
        this.fallbackCopyToClipboard(text);
    }
}

fallbackCopyToClipboard(text) {
    const textarea = document.createElement('textarea');
    textarea.value = text;
    textarea.style.position = 'fixed';
    textarea.style.opacity = '0';
    document.body.appendChild(textarea);
    textarea.select();
    
    try {
        document.execCommand('copy');
    } finally {
        document.body.removeChild(textarea);
    }
}
```
