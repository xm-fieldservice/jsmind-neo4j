## ✅ 已实现功能

### 快捷键定义

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| **Ctrl+C** | 复制节点 | 复制选中节点及所有子节点到剪贴板 |
| **Ctrl+X** | 剪切节点 | 剪切选中节点（删除原节点） |
| **Ctrl+V** | 粘贴节点 | 粘贴剪贴板中的节点到选中节点下 |

### 功能特性

1. **复制（Ctrl+C）**
   - ✅ 复制选中节点及其所有子节点
   - ✅ 保留节点结构、内容、属性
   - ✅ 不删除原节点
   - ✅ 可多次粘贴

2. **剪切（Ctrl+X）**
   - ✅ 剪切选中节点及其所有子节点
   - ✅ 保留节点结构、内容、属性
   - ✅ 删除原节点
   - ✅ 只能粘贴一次
   - ✅ 根节点不可剪切

3. **粘贴（Ctrl+V）**
   - ✅ 粘贴为选中节点的子节点
   - ✅ 自动生成新的节点ID
   - ✅ 保持原有的层级结构
   - ✅ 自动触发保存

### 3. 全局快捷键绑定

**文件**: `mindmap-standalone.html`

**实现方式**:
```javascript
bindGlobalShortcuts() {
    document.addEventListener('keydown', (e) => {
        // 检查是否在编辑状态
        const isEditing = document.activeElement.tagName === 'INPUT' || 
                         document.activeElement.tagName === 'TEXTAREA';
        
        if (isEditing) return;  // 编辑状态不拦截
        
        // Ctrl+C - 复制
        if (e.ctrlKey && e.key === 'c') {
            e.preventDefault();
            this.ops.copyNode();
        }
        
        // Ctrl+X - 剪切
        if (e.ctrlKey && e.key === 'x') {
            e.preventDefault();
            this.ops.cutNode();
        }
        
        // Ctrl+V - 粘贴
        if (e.ctrlKey && e.key === 'v') {
            e.preventDefault();
            this.ops.pasteNode();
        }
    });
}
```

## 🎯 功能流程

### 复制流程

```
1. 用户选择节点
2. 按 Ctrl+C
3. 节点数据（包括子节点）深拷贝到剪贴板
4. 显示提示："节点已复制"
5. 可多次粘贴
```

### 剪切流程

```
1. 用户选择节点（非根节点）
2. 按 Ctrl+X
3. 节点数据深拷贝到剪贴板
4. 标记为剪切操作
5. 显示提示："节点已剪切"
6. 粘贴时删除原节点
```

### 粘贴流程

```
1. 用户选择目标父节点
2. 按 Ctrl+V
3. 从剪贴板读取节点数据
4. 递归创建节点树（生成新ID）
5. 如果是剪切操作：
   - 删除原节点
   - 清空剪贴板
6. 如果是复制操作：
   - 保留剪贴板数据
7. 自动保存
8. 显示提示："节点已粘贴"
```

### 3. 递归粘贴节点树

```javascript
addNodeTree(parent, nodeData) {
    const newId = 'node_' + Date.now() + '_' + Math.random().toString(36).substr(2, 9);
    
    const node = this.jm.add_node(parent, newId, nodeData.topic, {
        direction: 'right'
    });
    
    if (node) {
        // 复制节点数据
        if (nodeData.data) {
            node.data = JSON.parse(JSON.stringify(nodeData.data));
        }
        
        // 递归添加子节点
        if (nodeData.children && nodeData.children.length > 0) {
            nodeData.children.forEach(child => {
                this.addNodeTree(node, child);
            });
        }
    }
    
    return node;
}
```
