## 🎯 重构目标

### 架构合规性

- **ContextMenuManager** - 右键菜单管理器 ✅

## 📦 模块职责划分

### 1. MindmapController.js（脑图控制器）
**职责**: 脑图生命周期管理和核心业务协调

```javascript
class MindmapController {
    constructor(options = {}) {
        this.mindmapId = options.mindmapId;
        this.container = options.container;
        this.jm = null;
        
        // 依赖注入
        this.dataManager = null;
        this.renderer = null;
        this.eventManager = null;
        this.operations = null;
    }
    
    // 核心API
    async initialize()           // 初始化脑图
    async createMindmap(data)    // 创建新脑图
    async saveMindmap()          // 保存脑图
    async loadMindmap(id)        // 加载脑图
    async deleteMindmap(id)      // 删除脑图
    destroy()                    // 销毁脑图实例
}
```

**依赖**:
- ✅ AutogenUnifiedStorage（存储）
- ✅ AutogenEventBus（事件）
- ✅ ErrorHandler（错误处理）

---

### 2. MindmapDataManager.js（数据管理器）
**职责**: 脑图数据的CRUD操作和格式转换

```javascript
class MindmapDataManager {
    constructor(options = {}) {
        this.storage = options.storage || window.AutogenUnifiedStorage;
        this.eventBus = options.eventBus || window.AutogenEventBus;
    }
    
    // 核心API
    async loadInitialData()              // 加载初始数据
    async saveData(mindmapId, data)      // 保存数据
    async loadData(mindmapId)            // 加载数据
    async deleteData(mindmapId)          // 删除数据
    getCurrentMindId()                   // 获取当前脑图ID
    setCurrentMindContext(id)            // 设置当前上下文
    convertToMDFormat(data)              // 转换为MD格式
    convertFromMDFormat(md)              // 从MD格式转换
}
```

**依赖**:
- ✅ AutogenUnifiedStorage（统一存储）
- ✅ MD底座数据结构（数据格式）

---

### 3. MindmapRenderer.js（渲染器）
**职责**: 脑图UI渲染和视图控制

```javascript
class MindmapRenderer {
    constructor(jm, options = {}) {
        this.jm = jm;
        this.container = options.container;
    }
    
    // 核心API
    renderMindmap(data)          // 渲染脑图
    updateNode(nodeId, data)     // 更新节点
    refreshView()                // 刷新视图
    zoomToFit()                  // 缩放适应
    expandAll()                  // 展开所有
    collapseAll()                // 折叠所有
    toggleFullscreen()           // 切换全屏
}
```

**依赖**:
- jsMind API

---

### 4. MindmapEventManager.js（事件管理器）
**职责**: 脑图事件绑定和处理

```javascript
class MindmapEventManager {
    constructor(jm, options = {}) {
        this.jm = jm;
        this.eventBus = options.eventBus || window.AutogenEventBus;
        this.handlers = {};
    }
    
    // 核心API
    setupEventHandlers()         // 设置事件处理器
    bindNodeEvents()             // 绑定节点事件
    bindShortcutKeys()           // 绑定快捷键
    triggerMindmapEvent(name, data)  // 触发脑图事件
    on(eventName, handler)       // 监听事件
    off(eventName, handler)      // 取消监听
}
```

**依赖**:
- ✅ AutogenEventBus（事件总线）

---

### 5. MindmapUtils.js（工具函数）
**职责**: 通用工具函数

```javascript
class MindmapUtils {
    static generateNodeId()      // 生成节点ID
    static formatTimestamp()     // 格式化时间戳
    static validateMindmapData(data)  // 验证数据格式
    static deepClone(obj)        // 深拷贝
    static debounce(fn, delay)   // 防抖
    static throttle(fn, delay)   // 节流
}
```

## ⚠️ 风险评估

### 高风险项
1. **Phase 5: 重构控制器**
   - 风险：可能破坏现有功能
   - 缓解：完整的回归测试

2. **依赖关系复杂**
   - 风险：模块间依赖可能导致循环引用
   - 缓解：使用依赖注入，明确依赖方向

### 中风险项
1. **数据管理器重构**
   - 风险：数据格式转换可能出错
   - 缓解：保留原有数据格式，增加兼容层

2. **事件管理器重构**
   - 风险：事件绑定可能遗漏
   - 缓解：详细的事件清单和测试
