# 详情页工作栏测试指南

## 🚀 **快速启动测试环境** ⭐

### **一键启动（推荐）**
```
双击 column-sources/detail/启动测试.bat
```

**自动完成**：
- ✅ 清理8000端口
- ✅ 启动HTTP服务器
- ✅ 打开详情页
- ✅ 等待你点击"🧪 测试"按钮

**然后**：
1. 在详情页点击"🧪 测试"按钮
2. 测试台在新窗口打开
3. 点击节点列表中的任意节点
4. 切换回详情页查看数据加载

---

## 🎯 **测试架构说明**

### **真实业务流程**
```
其他页面（脑图/列表） → 点击节点 
    ↓
触发事件：node:selected
    ↓
详情页监听事件 
    ↓
从数据底座加载数据
    ↓
显示节点详情
```

### **测试台模拟流程**
```
测试台 → 选择测试节点
    ↓
点击"发送选中节点"
    ↓
触发 node:selected 事件（模拟点击）
    ↓
详情页接收事件
    ↓
从 test-data.json 加载数据
    ↓
显示节点详情
```

   - ✅ 右侧：工作栏预览区域

### **测试3：数据加载功能** ⭐ 核心

#### 🎉 **新功能：节点列表选择**

测试台现在提供了更便捷的节点选择方式！

#### 测试步骤：

**步骤1**：查看节点列表
- 测试台左侧应该显示5个测试节点
- 每个节点显示：
  - ID（如 test_node_001）
  - 标题（如 项目管理系统重构）
  - 标签（如 重要、进行中、项目）

**步骤2**：点击节点（⭐ 关键步骤 - 自动发送）
- **直接点击任意节点**（如 test_node_001）
- 节点会高亮显示（紫色边框）
- **自动触发事件并发送到详情页**
- **观察控制台输出**（重要）：
  ```
  [测试台] 已选中节点: test_node_001
  [测试台] 触发节点选择事件: test_node_001
  [测试台] ✓ 已向父窗口发送事件
  [DetailColumn] 接收到节点选择事件: test_node_001
  [DetailColumn] 开始处理节点选择: test_node_001
  [DetailColumnCore] 加载节点数据: test_node_001
  [DetailColumnCore] 节点加载成功: {...}
  [DetailColumn] 节点处理完成: test_node_001
  ```

**步骤3**：查看详情页
- **切换到详情页窗口**，应该看到：
  - ✅ 标题：项目管理系统重构
  - ✅ 节点ID：ID: test_node_001
  - ✅ 内容：完整的Markdown内容
  - ✅ 标签：重要、进行中、项目（高亮显示）
  - ✅ 图片：架构图显示在附件区
  - ✅ 附件：架构设计文档.md显示

**步骤4**：测试其他节点
- 回到测试台，点击其他节点（如 test_node_002、test_node_003）
- 每次点击都会自动发送到详情页
- 切换到详情页查看内容是否更新

**步骤5**：批量测试（可选）
- 点击"📤 依次发送全部"按钮
- 确认对话框后，系统会自动依次发送所有5个节点
- 观察每个节点是否正确加载
- **注意**：每个节点之间有1秒延迟

**步骤5**：手动输入（高级）
- 点击"⌨️ 手动输入"按钮
- 显示JSON输入框
- 可以手动输入自定义数据
- 再次点击可切换回列表模式

1. 加载任意测试节点（如 test_node_001）
2. 观察"输出监控"区域是否有输出

## 🐛 **可能的问题**

### 问题1：跨域错误
**症状**：控制台显示 CORS 错误  
**原因**：测试台作为子窗口访问父窗口  
**解决**：暂时忽略，或修改为同域测试

### 问题2：文件加载失败
**症状**：test-data.json 404错误  
**原因**：路径不正确  
**解决**：检查文件是否在 column-sources/detail/ 目录

### 问题3：数据未显示
**症状**：点击发送后无反应  
**原因**：可能是 window.parent.detailColumn 未找到  
**解决**：查看控制台错误日志
