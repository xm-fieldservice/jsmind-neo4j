# 详情页工作栏 - 事件驱动架构说明

## 🎯 **设计理念**

### **为什么使用事件驱动？**

**真实业务场景**：
```
脑图页面点击节点 → 详情页显示节点内容
列表页面点击条目 → 详情页显示条目详情
搜索结果点击 → 详情页显示搜索项
```

**统一的解决方案**：事件驱动架构
- 📡 发送方：只需触发 `node:selected` 事件
- 📡 接收方：详情页监听事件并处理
- 🔌 解耦：双方不需要直接依赖

---

## 🔧 **架构实现**

### **1. 事件定义**

#### **事件名称**
```javascript
'node:selected'
```

#### **事件数据**
```javascript
{
  nodeId: "node_123"  // 节点ID（必填）
}
```

---

### **2. 发送方实现**

#### **方式1：使用原生CustomEvent（推荐）**

```javascript
// 触发节点选择事件
const event = new CustomEvent('node:selected', {
  detail: { nodeId: 'node_123' },
  bubbles: true
});

window.dispatchEvent(event);
```

**适用场景**：
- 同一窗口内的组件通信
- 不依赖外部库
- 浏览器原生支持

---

#### **方式2：使用AutogenEventBus**

```javascript
// 通过统一事件总线发送
window.AutogenEventBus.emit('node:selected', { 
  nodeId: 'node_123' 
});
```

**适用场景**：
- 跨窗口通信
- 需要事件历史记录
- 需要事件优先级控制
- 需要中间件处理

---

### **3. 接收方实现（详情页）**

#### **初始化时注册监听器**

```javascript
class DetailColumnCore {
  init() {
    // ... 其他初始化
    
    this.listenNodeSelection(); // 注册事件监听
  }
  
  listenNodeSelection() {
    // 方式1：监听原生事件
    window.addEventListener('node:selected', async (event) => {
      const nodeId = event.detail?.nodeId;
      if (nodeId) {
        await this.handleNodeSelection(nodeId);
      }
    });
    
    // 方式2：监听EventBus事件（兼容）
    if (window.AutogenEventBus) {
      window.AutogenEventBus.on('node:selected', async (data) => {
        const nodeId = data?.nodeId;
        if (nodeId) {
          await this.handleNodeSelection(nodeId);
        }
      });
    }
  }
  
  async handleNodeSelection(nodeId) {
    // 从数据底座加载数据
    await this.loadNodeFromTestData(nodeId);
  }
}
```

window.addEventListener('node:selected', async (event) => {

  await handleNodeSelection(nodeId);

### **步骤4：数据加载**
```javascript
// 详情页从数据底座加载
async function handleNodeSelection(nodeId) {
  // 1. 从数据底座获取数据
  const response = await fetch(`/data/nodes.json`);
  const data = await response.json();
  const node = data.nodes.find(n => n.id === nodeId);
  
  // 2. 渲染到UI
  renderNodeDetails(node);
}
```

## 🧪 **测试台的模拟方式**

### **测试台的角色**
测试台模拟"其他页面点击节点"的行为。

### **实现方式**

```javascript
// 测试台发送事件到父窗口（详情页）
function sendSelectedNode() {
  const nodeId = TestHarness.selectedNodeId;
  
  // 创建事件
  const event = new CustomEvent('node:selected', {
    detail: { nodeId: nodeId },
    bubbles: true
  });
  
  // 发送到父窗口
  if (window.opener) {
    window.opener.dispatchEvent(event);
  }
}
```

### **为什么是 window.opener？**

```
详情页窗口 (window)
    ↓ 点击"测试"按钮
测试台窗口 (window.open)
    ↓ window.opener 指向
详情页窗口 (父窗口)
```

## ✅ **优势总结**

### **1. 解耦**
- 发送方不需要知道接收方的具体实现
- 接收方可以独立开发和测试

### **2. 可扩展**
- 可以有多个接收方监听同一事件
- 可以添加中间件处理事件

### **3. 可测试**
- 测试台可以轻松模拟事件
- 不需要依赖真实的发送方

### **4. 符合真实场景**
- 完全模拟真实的业务流程
- 测试结果更可靠

## 📋 **事件命名规范**

### **格式**
```
<目标>:<动作>
```

### **示例**
```javascript
'node:selected'      // 节点被选中
'node:updated'       // 节点被更新
'node:deleted'       // 节点被删除
'column:activated'   // 工作栏被激活
'column:deactivated' // 工作栏被停用
```
