# 详情页工作栏 - 正确访问方式

## ✅ **正确访问方式**

### **步骤1：启动HTTP服务器**

确保8000端口的HTTP服务器正在运行。

检查方法：
```powershell
netstat -ano | findstr "8000"
```

如果没有运行，请启动服务器。

---

### **步骤2：通过HTTP访问详情页**

在浏览器地址栏输入：
```
http://localhost:8000/column-sources/detail/detail-column-layout.html
```

**重要**：必须使用 `http://` 协议，不能直接双击HTML文件！

---

### **步骤3：打开测试台**

点击详情页右上角的"🧪 测试"按钮。

测试台会在新窗口打开。

---

## ❌ **错误访问方式**

### **方式1：直接双击HTML文件**
```
file:///D:/AI-Projects/.../detail-column-layout.html  ❌ 错误
```

**问题**：浏览器会阻止 `file://` 协议的跨域请求（CORS错误）

---

### **方式2：从文件资源管理器拖拽到浏览器**
```
file:///D:/AI-Projects/.../detail-column-layout.html  ❌ 错误
```

**问题**：同样是 `file://` 协议，会遇到CORS问题

---

## 🔧 **降级模式说明**

如果确实无法通过HTTP访问，测试台会自动进入**降级模式**：

### **降级模式功能**
- ✅ 节点列表仍可使用（嵌入式数据）
- ✅ 节点选择和发送功能正常
- ✅ 数据会发送到父窗口的详情页
- ⚠️ 右侧预览区域不可用
- ⚠️ 无法加载完整的节点内容

### **降级模式提示**
```
节点列表顶部会显示：
⚠️ 使用嵌入式数据。建议通过 http://localhost:8000 访问以获取完整数据。

预览区域会显示：
⚠️ 无法加载工作栏预览
原因：Failed to fetch
```

## 🎯 **推荐工作流程**

### **完整测试流程（推荐）**
```
1. 启动HTTP服务器
2. 访问 http://localhost:8000/column-sources/detail/detail-column-layout.html
3. 点击"🧪 测试"按钮
4. 选择测试节点
5. 点击"发送选中节点"
6. 观察数据加载
```

### **快速测试流程（降级模式）**
```
1. 直接双击 test-harness.html
2. 选择测试节点（使用嵌入式数据）
3. 点击"发送选中节点"
4. 数据会尝试发送到父窗口
```

**注意**：降级模式下，父窗口可能不存在，发送会失败。

---

## 📋 **CORS错误排查**

如果看到以下错误：
```
Access to fetch at 'file:///.../test-data.json' from origin 'null' 
has been blocked by CORS policy
```

**解决方案**：
1. ✅ 使用 `http://localhost:8000` 访问
2. ❌ 不要使用 `file://` 协议
3. ✅ 确保HTTP服务器正在运行

---

## 💡 **提示**

### **如何判断当前访问方式**

查看浏览器地址栏：
```
http://localhost:8000/...        ✅ 正确（HTTP协议）
file:///D:/AI-Projects/...       ❌ 错误（FILE协议）
```

### **快速切换**

如果已经用 `file://` 打开：
1. 复制当前URL的文件路径部分
2. 替换为：`http://localhost:8000/column-sources/detail/detail-column-layout.html`
3. 刷新页面

---
