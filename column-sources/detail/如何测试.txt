详情页工作栏 - 快速测试指南
================================

📋 一键启动测试
--------------------------------
双击 【启动测试.bat】 即可！

自动完成：
  ✓ 启动HTTP服务器（8000端口）
  ✓ 打开详情页
  ✓ 等待测试

然后：
  1. 点击详情页右上角【🧪 测试】按钮
  2. 测试台窗口会弹出
  3. 点击测试节点列表中的任意节点
  4. 切换回详情页窗口查看数据


🎯 测试什么？
--------------------------------
✓ 事件驱动架构
  - 点击节点 → 触发事件 → 详情页加载数据

✓ 数据加载
  - 从 test-data.json 加载节点数据
  - 显示标题、内容、标签、图片、附件

✓ UI渲染
  - Markdown内容渲染
  - 标签高亮显示
  - 图片和附件显示


💡 注意事项
--------------------------------
⚠️ 必须通过HTTP服务器访问（不能双击HTML）
⚠️ 测试台必须从详情页打开（不能直接打开）
⚠️ 测试完成后关闭窗口即可（服务器继续运行）
