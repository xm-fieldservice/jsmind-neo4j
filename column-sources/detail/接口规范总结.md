# 详情页工作栏 - 接口规范总结

## 📥 **输入参数**

### **1. nodeId** （必填）⭐
```typescript
nodeId: string
```

**说明**：
- 要加载的节点ID
- 必填参数
- 示例：`"test_node_001"`

**使用场景**：
- 从脑图点击节点后，传入nodeId
- 从列表选择条目后，传入nodeId
- 从搜索结果点击后，传入nodeId

---

### **2. nodeData** （可选）
```typescript
nodeData?: {
  id: string;              // 节点ID
  topic: string;           // 节点标题
  content: string;         // Markdown格式内容
  tags: string[];          // 标签数组（简单字符串）
  images: string[];        // 图片URL数组
  attachments: Object[];   // 附件对象数组
  created_at: string;      // 创建时间（ISO格式）
  updated_at: string;      // 更新时间（ISO格式）
}
```

**说明**：
- 节点完整数据对象（可选）
- 如果提供，则直接加载
- 如果不提供，通过nodeId从数据底座查询

**示例**：
```json
{
  "id": "test_node_001",
  "topic": "项目管理系统重构",
  "content": "# 项目管理系统重构\n\n## 背景\n...",
  "tags": ["重要", "进行中", "项目"],
  "images": [],
  "attachments": [],
  "created_at": "2025-09-15T10:30:00",
  "updated_at": "2025-10-01T15:20:00"
}
```

---

### **3. tagGroups** （可选）⭐
```typescript
tagGroups?: Array<{
  name: string;     // 分组名称
  tags: string[];   // 该分组下的标签列表
}>
```

**说明**：
- 标签组配置（来自数据底座）
- 用于动态生成标签面板
- 一级为分组名，二级为该分组下的标签列表
- 如果不提供，使用工作栏内置的默认标签组

**示例**：
```json
[
  {
    "name": "优先级",
    "tags": ["重要", "紧急", "一般"]
  },
  {
    "name": "状态",
    "tags": ["进行中", "已完成", "待处理", "已取消"]
  },
  {
    "name": "类型",
    "tags": ["项目", "任务", "目标", "想法", "架构", "开发", "测试"]
  }
]
```

---

### **4. editMode** （可选）
```typescript
editMode?: 'view' | 'edit' | 'fullscreen'
```

**说明**：
- 编辑模式
- 默认值：`'edit'`
- 选项：
  - `view`: 只读模式
  - `edit`: 编辑模式
  - `fullscreen`: 全屏编辑模式

---

## 📤 **输出参数**

### **1. currentNode** ⭐
```typescript
currentNode: {
  id: string;
  topic: string;
  content: string;
  tags: string[];
  images: string[];
  attachments: Array<{
    name: string;
    type: string;
    size: string;
    url: string;
  }>;
  created_at: string;
  updated_at: string;
}
```

**说明**：
- 当前编辑的节点完整数据
- **格式与数据底座完全一致**
- 每次字段变化时立即输出
- 可直接保存回数据底座

**示例**：
```json
{
  "id": "test_node_001",
  "topic": "项目管理系统重构",
  "content": "# 项目管理系统重构\n\n## 背景\n...",
  "tags": ["重要", "进行中", "项目"],
  "images": ["data:image/svg+xml,..."],
  "attachments": [
    {
      "name": "架构设计文档.md",
      "type": "markdown",
      "size": "15.2 KB",
      "url": "#"
    }
  ],
  "created_at": "2025-09-15T10:30:00",
  "updated_at": "2025-10-01T15:20:00"
}
```

**更新频率**：`onChange`（每次变化时）

---

### **2. selectedTags**
```typescript
selectedTags: string[]
```

**说明**：
- 当前选中的标签列表
- 简单字符串数组
- 与 `currentNode.tags` 保持同步

**示例**：
```json
["重要", "进行中", "项目"]
```

**更新频率**：`onChange`

---

### **3. hasUnsavedChanges**
```typescript
hasUnsavedChanges: boolean
```

**说明**：
- 是否有未保存的修改
- 用于提示用户保存

**示例**：`true` 或 `false`

**更新频率**：`onChange`

## 🎯 **标签数据格式详解**

### **为什么使用简单字符串数组？**

**优势**：
- ✅ 与MD格式标签一致
- ✅ 与现有代码完全兼容
- ✅ 简单直观，易于处理
- ✅ 无需修改现有逻辑

**数据流**：
```
数据底座 → tags: ["重要", "进行中", "项目"]
    ↓
详情页加载 → 高亮匹配的标签chip
    ↓
用户点击标签 → 更新tags数组
    ↓
输出currentNode → tags: ["重要", "进行中", "紧急"]
    ↓
保存回数据底座 → tags: ["重要", "进行中", "紧急"]
```

---

### **标签组（tagGroups）的作用**

**作用**：
- 动态生成标签面板
- 提供可选的标签列表
- 支持分组显示

**HTML结构**：
```html
<div class="tag-group-row">
    <span class="tag-group-name">优先级</span>
    <div class="tag-chip" data-group="优先级" data-tag="重要">重要</div>
    <div class="tag-chip" data-group="优先级" data-tag="紧急">紧急</div>
    <div class="tag-chip" data-group="优先级" data-tag="一般">一般</div>
</div>
```

**加载逻辑**：
1. 如果提供了 `tagGroups`，使用它动态生成标签面板
2. 如果没有提供，使用内置的默认标签组
3. 根据 `nodeData.tags` 高亮匹配的标签

## 📊 **完整数据流示例**

### **场景：从脑图加载节点**

**1. 脑图发送**：
```javascript
// 触发事件
window.dispatchEvent(new CustomEvent('node:selected', {
  detail: {
    nodeId: 'test_node_001'
  }
}));
```

**2. 详情页接收**：
```javascript
// 监听事件
window.addEventListener('node:selected', async (event) => {
  const nodeId = event.detail.nodeId;
  
  // 从数据底座加载
  const nodeData = await loadFromDataBase(nodeId);
  
  // 渲染节点
  renderNode(nodeData);
});
```

**3. 加载数据**：
```json
{
  "id": "test_node_001",
  "topic": "项目管理系统重构",
  "content": "...",
  "tags": ["重要", "进行中", "项目"]
}
```

**4. 渲染标签**：
```javascript
// 高亮匹配的标签
loadTags(nodeData.tags);  // ["重要", "进行中", "项目"]
```

**5. 用户编辑**：
- 修改标题 → `currentNode.topic` 更新
- 点击"紧急"标签 → `currentNode.tags` 更新
- 粘贴图片 → `currentNode.images` 更新

**6. 输出数据**：
```javascript
// 每次变化时输出
setOutput('currentNode', {
  id: 'test_node_001',
  topic: '项目管理系统重构（已更新）',
  content: '...',
  tags: ['重要', '进行中', '项目', '紧急'],  // 新增了"紧急"
  images: ['data:image/...'],  // 新增了图片
  ...
});
```

**7. 保存回数据底座**：
```javascript
// 输出数据格式与数据底座一致，可直接保存
await saveToDataBase(currentNode);
```

## 💾 **数据持久化逻辑** ⭐

### **核心需求**
当用户在详情页编辑内容后，数据需要自动同步保存到数据底座。

### **保存策略：Upsert（自动判断）**

```
获取编辑后的数据
    ↓
查询数据底座：节点是否存在？
    ↓
    ├─ 存在 → 旧节点 → UPDATE（覆盖）
    │       ↓
    │   PUT /api/nodes/{nodeId}
    │
    └─ 不存在 → 新节点 → INSERT（追加）
            ↓
        POST /api/nodes
```

---

### **判断逻辑**

**步骤1**：获取节点ID
```javascript
const nodeId = currentNode.id;
```

**步骤2**：查询数据底座
```javascript
// 方式1：API查询
const response = await fetch(`/api/nodes/${nodeId}`);

if (response.status === 200) {
    // 节点存在 → 旧节点
    isNew = false;
} else if (response.status === 404) {
    // 节点不存在 → 新节点
    isNew = true;
}
```

**步骤3**：执行相应操作
```javascript
if (isNew) {
    // 新节点 → INSERT
    await fetch('/api/nodes', {
        method: 'POST',
        body: JSON.stringify(currentNode)
    });
} else {
    // 旧节点 → UPDATE
    await fetch(`/api/nodes/${nodeId}`, {
        method: 'PUT',
        body: JSON.stringify(currentNode)
    });
}
```

**步骤4**：触发事件
```javascript
window.dispatchEvent(new CustomEvent('node.saved', {
    detail: {
        nodeId: nodeId,
        data: currentNode,
        isNew: isNew,
        operation: isNew ? 'insert' : 'update',
        timestamp: Date.now()
    }
}));
```

---

### **自动保存配置**

```javascript
{
    autoSave: true,          // 启用自动保存
    saveInterval: 3000,      // 3秒防抖
    saveStrategy: 'upsert'   // 自动判断新增或更新
}
```

**工作流程**：
1. 用户编辑内容 → 标记为"脏数据"
2. 3秒内无新编辑 → 触发自动保存
3. 查询节点是否存在 → 判断操作类型
4. 执行保存 → 触发事件
5. 更新UI状态（已保存/保存失败）

---

### **数据底座API**

**检查节点存在**：
```
GET /api/nodes/{nodeId}
```

**更新节点（覆盖）**：
```
PUT /api/nodes/{nodeId}
Body: 完整节点数据
```

**新增节点（追加）**：
```
POST /api/nodes
Body: 完整节点数据
```
