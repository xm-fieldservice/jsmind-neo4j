# 智能浏览器 - 快速开始指南

## 🚀 5分钟快速上手

### 步骤1: 安装依赖 (2分钟)

```powershell
# 进入项目目录
cd backend/intelligent_browser

# 安装Python依赖
pip install -r requirements.txt

# 安装Playwright浏览器
playwright install chromium
```

### 步骤2: 配置API Key (1分钟)

在项目根目录的 `.env` 文件中添加:

```bash
# 通义千问API Key
DASHSCOPE_API_KEY=sk-your-api-key-here
```

### 步骤3: 索引本地文档 (1分钟)

```powershell
# 索引Autogen文档
python tests/test_local_rag.py
```

### 步骤4: 启动服务 (30秒)

```powershell
# 启动后端服务
python main.py
```

服务启动后会显示:
```
🚀 启动智能浏览器服务...
📍 地址: http://0.0.0.0:8001
📚 API文档: http://0.0.0.0:8001/docs
```

### 步骤5: 打开前端页面 (30秒)

双击打开项目根目录下的:
```
intelligent-browser-demo.html
```

或在浏览器中打开:
```
file:///d:/AI-Projects/project_manager(neo4j+d3.jsECHART)/intelligent-browser-demo.html
```

## 🔧 故障排查

### 问题1: 后端服务启动失败

**症状**: `ModuleNotFoundError: No module named 'xxx'`

**解决**:
```powershell
pip install -r requirements.txt
```

### 问题2: API Key错误

**症状**: `401 Unauthorized` 或 `API Key未配置`

**解决**:
1. 检查 `.env` 文件中的 `DASHSCOPE_API_KEY`
2. 确保API Key有效
3. 重启服务

### 问题3: 前端无法连接后端

**症状**: 前端显示 "后端服务未启动"

**解决**:
1. 确认后端服务已启动 (`python main.py`)
2. 检查端口8001是否被占用
3. 检查防火墙设置

### 问题4: Playwright浏览器未安装

**症状**: `playwright._impl._api_types.Error: Executable doesn't exist`

**解决**:
```powershell
playwright install chromium
```

### 问题5: ChromaDB索引为空

**症状**: 查询返回 "文档中没有相关信息"

**解决**:
```powershell
# 重新索引文档
python tests/test_local_rag.py
```

## 🎓 进阶使用

### 使用API直接调用

response = requests.post('http://localhost:8001/api/intelligent-browser/ask', json={

print(result['answer'])
