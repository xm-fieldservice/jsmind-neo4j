## 超时配置指引（OpenAI 兼容运行器）

- 非流式模式下，运行器的 `timeout` 为“请求总耗时”（从请求发出到完整响应返回；包含排队/计算/传输）。
- 超时优先级：`config.model_info.timeout` > `config.parameters.timeout` > 默认 120s < 环境变量覆盖（最高优先，>0 生效）。
- 本项目遵循“前端适配原则”：超时首选写入模型 JSON 的 `parameters.timeout`，避免后端硬编码。

参考文档：`docs/openai_compat_runner_说明.md`

示例（PowerShell）：

```powershell
# 临时提升全局超时为 60s（无需修改 JSON）
$env:OPENAI_TIMEOUT = "60"

# 恢复默认
Remove-Item Env:OPENAI_TIMEOUT -ErrorAction SilentlyContinue
Remove-Item Env:OPENAI_COMPAT_TIMEOUT -ErrorAction SilentlyContinue
```
